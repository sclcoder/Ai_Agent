1. 创建一个包含'姓名'和'年龄'两列的DataFrame，数据如下：

| 姓名 | 年龄 |

|----|----|

|Alice|25|

|Bob|30|

|Charlie|35|

然后计算所有人员的平均年龄。

**答案**：

```python
import pandas as pd
data = {    '姓名': ['Alice', 'Bob', 'Charlie'],    '年龄': [25, 30, 35]}
df = pd.DataFrame(data)
average_age = df['年龄'].mean()
print(average_age)
```

**分析**：导入 Pandas 库后，定义一个字典data，其中键为列名'姓名'和'年龄'，值分别为对应的列表数据。使用pd.DataFrame(data)将字典转换为DataFrame对象df。通过df['年龄']获取'年龄'列的数据，这是一个Series对象，再使用mean方法计算该Series的平均值，即所有人员的平均年龄，最后打印平均年龄，结果为 30.0。



2. 假设有一个DataFrame df如下：

|Fruit|Price|Quantity|

|----|----|----|

|Apple|2|5|

|Banana|1|8|

|Apple|3|3|

|Banana|1.5|6|

使用groupby函数按Fruit分组，计算每种水果的总销售额（销售额 = 价格 * 数量）。

**答案**：

```python
import pandas as pd
df = pd.DataFrame({    'Fruit': ['Apple', 'Banana', 'Apple', 'Banana'],    'Price': [2, 1, 3, 1.5],    'Quantity': [5, 8, 3, 6]})
df['Total_Sales'] = df['Price'] * df['Quantity']
result = df.groupby('Fruit')['Total_Sales'].sum()
print(result)
```

**分析**：首先导入 Pandas 库并创建df DataFrame。通过df['Total_Sales'] = df['Price'] * df['Quantity']计算出每一行的销售额并添加到新列'Total_Sales'中。然后使用df.groupby('Fruit')['Total_Sales'].sum()按Fruit分组，并对每组的Total_Sales列求和，得到每种水果的总销售额，最后打印结果，输出为：

Fruit

Apple    19

Banana   17

Name: Total_Sales, dtype: int64
