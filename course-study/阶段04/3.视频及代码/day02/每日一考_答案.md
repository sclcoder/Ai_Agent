### 操作题

1. 使用 Numpy 创建一个包含 1 到 10 的整数的一维数组，并将其重塑为 2 行 5 列的二维数组。

   提示：重塑方法reshape(形状)

   ```python
   import numpy as np
   
   # 创建一维数组
   arr = np.arange(1, 11)
   # 重塑为2行5列
   arr_reshaped = arr.reshape(2, 5)
   
   print(arr_reshaped)
   ```

   

2. 创建一个3*4的二维数组，并用[1,5]的随机整数进行填充

   ```python
   import numpy as np
   
   # 创建3×4的随机整数数组（范围[1,5]）
   arr = np.random.randint(1, 6, size=(3, 4))
   
   print(arr)
   ```
