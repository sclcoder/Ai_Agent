### 操作题

1. 创建一个3*4的二维数组，并用[1,5]的随机整数进行填充

   ```python
   import numpy as np
   
   # 创建3×4的随机整数数组（范围[1,5]）
   arr = np.random.randint(1, 6, size=(3, 4))
   
   print(arr)
   ```

   

2. 取出上述创建数组的前两行和后三列

   ```python
   # 切片：前两行和后三列
   sliced = arr[:2, -3:]
   
   print(sliced)
   ```

3. 使用 Pandas 创建一个Series对象，数据为[10, 20, 30, 40]，索引为['a', 'b', 'c', 'd']，然后获取索引为'b'的元素值。

**答案**：

```python
import pandas as pd
s = pd.Series([10, 20, 30, 40], index = ['a', 'b', 'c', 'd'])
value = s.loc['b']
print(value)
```

**分析**：首先导入 Pandas 库。然后使用pd.Series([10, 20, 30, 40], index = ['a', 'b', 'c', 'd'])创建Series对象s。接着使用loc索引器，通过s.loc['b']获取索引为'b'的元素值，并将其赋值给value，最后打印value，输出 20。
