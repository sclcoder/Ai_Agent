# Day02 · 第三节：广播 + 矩阵运算（P04）

> 视频 P04。**Day02 真正的重头戏**——这是 NumPy 区别于 Python list 的"超能力"，也是后面所有 ML / DL 框架（PyTorch / TensorFlow）共用的核心心法。
>
> 这一节如果只学**一个**——就是它。

---

## 为什么这一节最重要

iOS 老兵的直觉：你写过这种代码吗？

```swift
// 给数组每个元素加上同一个值
let arr = [1.0, 2.0, 3.0]
let scaled = arr.map { $0 * 2 }              // 每次循环

// 两个数组对位加
let a = [1.0, 2.0, 3.0]
let b = [10.0, 20.0, 30.0]
let sum = zip(a, b).map { $0 + $1 }          // zip + map
```

Swift / Python list 必须**写循环**——慢、丑、易错。

NumPy 给你这个：

```python
arr = np.array([1.0, 2.0, 3.0])
arr * 2                # [2., 4., 6.]      ← 一行
a + b                  # [11., 22., 33.]   ← 一行
```

**这就是"广播"**——**让"形状不同的数组"也能直接做运算**。它是 NumPy / PyTorch / TensorFlow 这套科学计算栈**最核心的设计**。

---

## 一句话定位

```
广播 (Broadcasting) = "形状不同的数组也能做对位运算的规则"
矩阵运算 (Matrix ops) = "线性代数里的真矩阵乘法、点积"
```

这一节学：

1. **逐元素运算**（同 shape）
2. **广播**（不同 shape，但满足规则）
3. **矩阵乘法**（线代意义上的乘法，和 `*` 不一样！）

---

## 第一部分：逐元素运算（同 shape）

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])
arr2 = np.array([[7, 8, 9], [10, 11, 12]])

arr1 + arr2
# [[ 8, 10, 12],
#  [14, 16, 18]]                ← 对位加

arr1 - arr2 / arr1 * arr2 / arr1 / arr2
# 全部"对位"运算
```

**规则**：两个数组 **shape 完全相同**——按位置一一对应运算。和 Python list 完全不一样（Python list `+` 是拼接）。

---

## 第二部分：标量广播（最简单的广播）

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])

arr1 + 5
# [[ 6,  7,  8],
#  [ 9, 10, 11]]
```

**心法**：标量 `5` 被"复制"到和 `arr1` 同样的 shape，然后对位加。

```
[[1,2,3],     [[5,5,5],     [[6,7,8],
 [4,5,6]] +    [5,5,5]]  =   [9,10,11]]
                 ↑
        概念上 NumPy 自动"广播"出来的
```

**实际不会真的复制**——NumPy 在底层用了一个高效的"伪复制"机制（zero-copy broadcasting），所以**广播不耗内存**。

---

## 第三部分：数组间广播（**核心难点**）

### 3.1 视频例子

```python
arr1 = np.array([[1, 2, 3]])         # shape: (1, 3)  ← 1 行 3 列
arr2 = np.array([[4], [5], [6]])     # shape: (3, 1)  ← 3 行 1 列

arr1 + arr2
# [[5, 6, 7],
#  [6, 7, 8],
#  [7, 8, 9]]
# shape: (3, 3)                       ← 结果 shape！
```

**这就是广播的威力**——`(1,3) + (3,1) = (3,3)`。

### 3.2 视频里的 3 条规则

#### 规则 1：维度数不同 → 小维度在最左边补 1

```python
arr1 = np.array([1, 2, 3])              # shape: (3,)        ← 1 维
arr2 = np.array([[4, 5, 6], [7, 8, 9]])  # shape: (2, 3)      ← 2 维

# 广播过程：
# arr1.shape = (3,)   ← 维度数小，左边补 1 → (1, 3)
# arr2.shape = (2, 3)
# 现在两个都是 2 维了
```

#### 规则 2：某维度大小不匹配 → 大小为 1 的维度被"拉伸"

```python
# 接上面，对齐后：
# arr1: (1, 3)   ← 第 0 维大小是 1
# arr2: (2, 3)   ← 第 0 维大小是 2

# 大小是 1 的维度"拉伸"成 2 → 都是 (2, 3) → 可以对位运算

arr1 + arr2
# [[5, 7, 9],
#  [8, 10, 12]]                          ← shape (2, 3)
```

**图示**：

```
arr1: [1, 2, 3]                       ← (3,) → 补 1 维 → (1, 3)
                                          ↓ 拉伸第 0 维
[[1, 2, 3],                            ← 概念上变成 (2, 3)
 [1, 2, 3]]
+
arr2:
[[4, 5, 6],
 [7, 8, 9]]
=
[[5, 7, 9],
 [8, 10, 12]]
```

#### 规则 3：都不匹配且都不是 1 → 报错

```python
arr5 = np.array([1, 2, 3])    # (3,)
arr6 = np.array([4, 5])       # (2,)

arr5 + arr6
# ❌ ValueError: shapes (3,) (2,) not broadcastable
# 因为 3 ≠ 2 且都不是 1，无法广播
```

但是：

```python
arr5 = np.array([1, 2, 3])    # (3,)
arr6 = np.array([4])          # (1,)

arr5 + arr6                   # ✅ 可以！(1,) 被拉伸成 (3,)
# [5, 6, 7]
```

### 3.3 广播规则的 **总判定流程**

```
要判断 a.shape 和 b.shape 能否广播？

Step 1: 把短的 shape 在左边补 1，让两者维度数相同
        例：(3,) + (2,3) → (1,3) + (2,3)

Step 2: 从右往左逐维度对比
        - 两边相同 → OK
        - 一边是 1 → OK（小的一边被拉伸）
        - 都不是 1 且不相同 → ❌ 报错

Step 3: 结果 shape = 每维取较大值
```

### 3.4 经典广播例子

```python
# 例 1：标量 + 数组 → 处处可加
arr + 5                       # 任何 shape OK

# 例 2：(M, N) + (N,) → 给每行加同一个向量
arr2d = np.zeros((100, 3))
bias = np.array([1, 2, 3])    # (3,)
arr2d + bias                  # (100, 3) + (3,) → (100, 3)，每行加上 [1,2,3]

# 例 3：(M, 1) + (1, N) → "外积"风格 → (M, N)
col = np.array([[1], [2], [3]])      # (3, 1)
row = np.array([10, 20, 30])         # (3,) → 广播为 (1, 3)
col + row                            # (3, 1) + (1, 3) → (3, 3)
# [[11, 21, 31],
#  [12, 22, 32],
#  [13, 23, 33]]

# 例 4：用广播算"中心化"（每行减去均值向量）
data = np.random.rand(100, 5)
mean = data.mean(axis=0)             # (5,)
centered = data - mean               # (100, 5) - (5,) → 每行减 (5,) → (100, 5)
```

### 3.5 iOS 老兵的直觉

```
广播 ≈ "Swift 里 zip 不要求长度相等的版本"

Swift 的 zip(a, b) 要求 a 和 b 一样长——少的截断、丢数据。
NumPy 广播：自动补齐 + 拉伸——不丢数据，结果更智能。
```

## 第四部分：矩阵乘法（**新人最爱踩的坑**）

### 4.1 `*` 不是矩阵乘法！

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])
arr2 = np.array([[6, 5, 4], [3, 2, 1]])

arr1 * arr2                  # 元素乘法（对位相乘）
# [[ 6, 10, 12],
#  [12, 10,  6]]              ← shape 不变
```

🔥 **新人 99% 在这里出错**——以为 `*` 是矩阵乘法，结果**算出莫名其妙的结果**。

### 4.2 真正的矩阵乘法：`@` / `np.dot` / `np.matmul`

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])   # (2, 3)
arr2 = np.array([[6, 5], [4, 3], [2, 1]])  # (3, 2)

arr1 @ arr2
# [[20, 14],
#  [56, 41]]                  ← shape: (2, 2)

# 三种等价写法
arr1 @ arr2                   # ← Python 3.5+ 推荐
np.dot(arr1, arr2)
np.matmul(arr1, arr2)
arr1.dot(arr2)
```

🔥 **矩阵乘法的形状规则**：

```
(M, K) @ (K, N) = (M, N)
         ↑          ↑
   左矩阵列数 == 右矩阵行数        结果是"左行 × 右列"
```

**视频例子拆解**：

```
arr1: (2, 3)      ← 2 行 3 列
arr2: (3, 2)      ← 3 行 2 列
       ↑           ↑
       3 == 3     OK

结果 shape: (2, 2)
```

如果维度不匹配：

```python
arr1 = np.array([[1,2,3]])   # (1, 3)
arr3 = np.array([[1,2,3]])   # (1, 3)
arr1 @ arr3                   # ❌ ValueError
# (1, 3) @ (1, 3): 3 ≠ 1 → 报错
```

### 4.3 矩阵 × 向量

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])    # (2, 3)
arr3 = np.array([6, 5, 4])                  # (3,)

arr1 @ arr3
# [28, 73]                                   ← shape (2,)
```

**形状**：`(2, 3) @ (3,) = (2,)`——结果是 1 维向量。

视频原 cell 输出的 `[28, 73]` 怎么算出来的？

```
arr1 @ arr3 = arr1 的每行点乘 arr3

[1, 2, 3] · [6, 5, 4] = 1*6 + 2*5 + 3*4 = 6 + 10 + 12 = 28
[4, 5, 6] · [6, 5, 4] = 4*6 + 5*5 + 6*4 = 24 + 25 + 24 = 73

结果: [28, 73]
```

### 4.4 `*` vs `@` 对照表（**记死它**）

| 算子 | 名称 | 形状要求 | 结果 |
|---|---|---|---|
| `*` | **元素乘** | shape 相同或可广播 | 同 shape 元素积 |
| `@` | **矩阵乘** | 左列 == 右行 | `(M,N) @ (N,P) = (M,P)` |
| `np.multiply` | 元素乘（同 `*`）| 同上 | 同上 |
| `np.dot` | 矩阵乘 / 点积 | 同 `@` | 同 `@` |
| `np.matmul` | 矩阵乘（同 `@`）| 同 `@` | 同 `@` |

### 4.5 实战：神经网络的"前向传播"就是矩阵乘法

```python
# 一个简单的全连接层：y = X @ W + b
X = np.random.rand(100, 4)        # 100 个样本，每个 4 维特征
W = np.random.rand(4, 3)           # 权重矩阵：4 输入 → 3 输出
b = np.array([0.1, 0.2, 0.3])      # 偏置 (3,)

y = X @ W + b                       # (100,4)@(4,3) + (3,) = (100,3)
                                    # 矩阵乘 + 广播
```

→ 后面 PyTorch / TensorFlow 里**所有神经网络层**都是这个套路。**这一节学透 = 后面省一年时间**。

## 第五部分：常见广播陷阱（4 个）

### 陷阱 1：`(M,) + (1, N)` —— 行向量被广播成"加到所有行"

```python
arr = np.random.rand(5, 3)
v = np.array([10, 20, 30])         # (3,) → 广播为 (1,3) → 每行加

arr + v                             # OK，每行加 [10,20,30]
```

### 陷阱 2：想"加到每列"忘了 reshape

```python
arr = np.random.rand(5, 3)
v = np.array([10, 20, 30, 40, 50]) # (5,) → 想加到每列

arr + v                             # ❌ ValueError！
# (5,3) + (5,) 不能广播：右侧补 1 → (1,5) → 第 1 维 5 ≠ 3

# 正确：把 v 变成 (5, 1)
arr + v.reshape(-1, 1)              # ✅ (5,3) + (5,1) → (5,3)，每列加
```

### 陷阱 3：以为 `(3, 1)` 和 `(3,)` 是同一回事

```python
a = np.array([1, 2, 3])             # (3,)
b = a.reshape(3, 1)                  # (3, 1)

a + a                                # (3,) + (3,) → (3,)
b + b                                # (3,1) + (3,1) → (3,1)
a + b                                # (3,) + (3,1) → (3,) → (1,3); (3,1) → 广播 → (3,3)!!
```

🔥 **`(3,) + (3, 1)` 会广播成 (3, 3)**——很多新人想 "对位加" 结果搞出三维结果，原因就是没意识到 shape 差一维。

**保险做法**：写运算前打印 shape：

```python
print(a.shape, b.shape)
result = a + b
print(result.shape)
```

### 陷阱 4：`*` 和 `@` 混用

```python
# 想算矩阵乘法
result = X * W                       # ❌ 元素乘，结果不对
result = X @ W                       # ✅ 矩阵乘

# 想算逐元素权重缩放
result = X @ scale                   # ❌ 当作矩阵乘
result = X * scale                   # ✅ 元素乘
```

→ 写之前**先想一下你要的是哪种**。

## 卡点汇总（5 大坑预警）

1. **广播规则 3 条** —— 不画 shape 图很难记，画一次就懂
2. **`*` 是元素乘、`@` 是矩阵乘** —— 90% 新人会混
3. **矩阵乘法要求"左列 == 右行"** —— `(M,K)@(K,N)=(M,N)`
4. **`(3,) + (3,1) = (3,3)`** —— 一维和二维的广播容易出意外
5. **`np.multiply` 是元素乘不是矩阵乘** —— 别被名字骗

## 速查表

```python
# 元素运算（同 shape 或可广播）
arr1 + arr2 / arr1 - arr2 / arr1 * arr2 / arr1 / arr2
arr1 ** 2                           # 元素平方
arr1 ** arr2                        # 元素幂

# 矩阵运算
arr1 @ arr2                         # 矩阵乘（推荐）
np.dot(arr1, arr2)                  # 等价
np.matmul(arr1, arr2)               # 等价

# 广播规则（心算）
# 1. 短 shape 在左侧补 1
# 2. 从右往左对比，相同或一边是 1 都 OK
# 3. 都不为 1 且不相同 → 报错
# 4. 结果 shape = 每维取大

# 常用广播姿势
arr2d + 标量                         # 全部元素加
arr2d + (3,)                        # 每行加同一个向量（前提：列数=3）
arr2d - arr2d.mean(axis=0)          # 每列去中心化（mean 是 (M,)）
arr2d - arr2d.mean(axis=1, keepdims=True)  # 每行去中心化（keepdims 保持 (M,1)）

# reshape 调整 shape 配合广播
v.reshape(-1, 1)                    # 变成 (n, 1) 列向量
v.reshape(1, -1)                    # 变成 (1, n) 行向量
v[:, None]                          # 同 reshape(-1, 1) 的快捷写法
v[None, :]                          # 同 reshape(1, -1)
```

## 自测题（**至少 3 题做出来才算理解了广播**）

> 不算结果直接做"形状推导"——给我说出每个表达式的 **shape**（不能广播就说 ❌）。

```python
a = np.zeros((4, 3))
b = np.zeros((3,))
c = np.zeros((4, 1))
d = np.zeros((1, 3))
e = np.zeros((4,))
f = np.zeros((4, 3, 5))
g = np.zeros((3, 5))
```

> 1. `a + b` 的 shape？
> 2. `a + c` 的 shape？
> 3. `a + d` 的 shape？
> 4. `a + e` 的 shape？
> 5. `c + d` 的 shape？
> 6. `a @ a.T` 的 shape？（`.T` 是转置）
> 7. `f + g` 的 shape？

<details>
<summary>👇 答案展开</summary>

1. `(4, 3)` —— `(4,3) + (3,)` → 右对齐 → `(4,3) + (1,3)` → OK
2. `(4, 3)` —— `(4,3) + (4,1)` → OK
3. `(4, 3)` —— `(4,3) + (1,3)` → OK
4. ❌ **报错** —— `(4,3) + (4,)` → 右对齐 → `(4,3) + (1,4)`，第 1 维 3≠4 → 报错。**新人很容易直觉以为能加，实际不行**
5. `(4, 3)` —— `(4,1) + (1,3)` → 双向拉伸 → `(4,3)`
6. `(4, 4)` —— `a.shape=(4,3)`, `a.T.shape=(3,4)`, `(4,3)@(3,4)=(4,4)`
7. `(4, 3, 5)` —— `(4,3,5) + (3,5)` → 右对齐 → `(4,3,5) + (1,3,5)` → OK

</details>

🔥 **如果第 4 题答错了**——再回去看 "陷阱 2"。
