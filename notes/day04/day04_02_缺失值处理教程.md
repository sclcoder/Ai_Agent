## 为什么数据会有缺失值

**真实世界里数据永远不全**——这是事实，不是异常。常见原因：

| 来源 | 例子 |
|---|---|
| **用户没填** | 注册表单"年龄"选填，没填 → NaN |
| **传感器故障** | 5 分钟一次的温度采样，某次设备死了 → NaN |
| **数据没采集** | 2010 年前没人记录 GPS → 所有 2010 年前的位置数据 NaN |
| **数据冲突丢弃** | 同一 user_id 两份矛盾记录，自动合并时其中一个字段被弃 |
| **业务上没有** | 一个用户没下过单，"最近订单金额"自然没值 → NaN |
| **合并时缺失** | 你用 `merge how='left'`，右表没匹配的 → NaN |

**重点**：NaN **不是脏数据**，是 **"信息真的没有"** 的合法表达。你的任务不是消灭它，是**决定怎么处理它**才让模型学得最好。

## 缺失值在 Pandas 里有 3 种形态（容易混）

```python
import numpy as np
import pandas as pd

np.nan      # NaN — 数值列的缺失（float 专属）
None        # None — Python 原生空对象，object 列的缺失
pd.NaT      # NaT — 日期列的缺失 ("Not a Time")
```

| 类型 | 出现在 | 长什么样 |
|---|---|---|
| `np.nan` | 数值列（int/float）| `NaN` |
| `None` | 字符串/对象列 | `None` 或 `NaN`（Pandas 内部统一）|
| `pd.NaT` | 日期列 | `NaT` |

**好消息**：Pandas 的 `isna()` / `dropna()` / `fillna()` **三种都能识别**——你不用区分。

**坏消息**：和 SQL 的 NULL 不太一样——`np.nan` **不等于自己**：

```python
np.nan == np.nan   # False  ← 注意！
np.nan == None     # False
```

**所以"判断是不是 NaN" 不能用 `==`，必须用 `isna()`**：

```python
df['col'] == np.nan       # ❌ 永远返回 False，错的
df['col'].isna()          # ✅ 正确判断
```

这是个 **新手最容易撞的坑**——记死它。

## 完整 4 步流程

```
1. 判断    →   2. 查看     →   3. 决策     →   4. 处理
   isna()       sum()        drop or fill    dropna / fillna
   ↓            ↓            ↓               ↓
"哪些缺?"    "缺多少?"     "怎么办?"        "执行"
```

每一步都有专门的 API，按顺序走。

## 第 1 步：判断 (isna / notna)

### 基本用法

```python
df.isna()         # 返回布尔 DataFrame，每个格子是不是 NaN
df.isnull()       # ← 完全等价的别名，看到不用懵
df.notna()        # 反过来：每个格子不是 NaN？（不常用，可以 ~df.isna() 替代）
```

### 单元格 vs 列 vs 整张表

```python
df['age'].isna()           # 一列：返回 Series of bool
df.isna()                  # 整张表：返回 DataFrame of bool
df['age'].isna().any()     # 这列有没有任何缺失？True/False
df.isna().any().any()      # 整张表有没有任何缺失？
```

### `isna` 在布尔筛选里很有用

```python
df[df['age'].isna()]       # 只看 age 缺失的行
df[df['age'].notna()]      # 只看 age 不缺失的行
df[df.isna().any(axis=1)]  # 任何一列有缺失的所有行
```

> **类比**：`isna` 是 Pandas 给你的"放大镜"，让你**先看清楚缺失的格局**再决定怎么处理。

## 第 2 步：查看缺失分布

拿到数据后**固定动作**——3 句话扫一眼。

### 必跑的 3 句

```python
# 1. 每列缺失多少个
df.isna().sum()
# col1     0
# col2    20
# col3   687

# 2. 每列缺失比例
df.isna().mean()        # 等价于 .sum() / len(df)
# col1   0.00
# col2   0.02
# col3   0.77

# 3. 每行有多少缺失（看哪些行最破）
df.isna().sum(axis=1).sort_values(ascending=False).head()
```

### `info()` 也间接告诉你

```python
df.info()
# RangeIndex: 891 entries
#  #   Column       Non-Null Count  ← 这一列就是"非空数"
# ...
```

`Non-Null Count` 列不等于总行数 → 那一列有缺失。

### 综合看板（实战常用）

```python
missing = df.isna().sum().sort_values(ascending=False)
missing_pct = (missing / len(df) * 100).round(1)
pd.DataFrame({'缺失数': missing, '缺失比例(%)': missing_pct})
```

输出：

```
        缺失数  缺失比例(%)
deck      688         77.2
age       177         19.9
embarked    2          0.2
其他       0           0.0
```

**这一张表是你做决策的依据**——下面讲怎么决策。

## 第 3 步：决策——drop 还是 fill？

这是缺失值处理的**真正难点**——API 容易，决策难。

### 决策树（建议背下来）

```
                    缺失比例多少？
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
      < 5%            5% ~ 30%            > 30%
        │                 │                 │
   一般填           看列的重要性          一般弃
   （fillna）         │                  （drop column）
                     │
              ┌──────┴──────┐
              │             │
          关键列         次要列
              │             │
          认真填        简单填或弃
       （建模 / 同组）  （众数/0）
```

### 几个具体规则

| 情况 | 建议 |
|---|---|
| 数值列、缺失 < 30%、有合理"代替值" | **填**（中位数 / 均值）|
| 数值列、缺失 > 70% | **弃这一列**（信息太少，硬填会引入偏差） |
| 字符串列、缺失少 | **填**（众数 / "Unknown"）|
| 目标列（y）有缺失 | **弃这些行**（没标签的样本没法训练）|
| 时间序列、连续测量 | **`ffill`（前向填充）** 或 `interpolate`（插值）|

### 没有"标准答案"

不同模型对缺失值耐受度不同：

- **线性回归 / SVM**：完全不能有 NaN
- **决策树 / 随机森林**：很多实现能直接处理 NaN
- **XGBoost / LightGBM**：原生支持 NaN，甚至**把"缺失"当一种信号利用**

知道你后续要用什么模型，**反推预处理策略**。

## 第 4 步 A：剔除 (`dropna`)

### 最简用法

```python
df.dropna()           # 删掉任何有缺失的行（默认 axis=0, how='any'）
```

**警告**：这个默认行为**经常删太多**——只要某行有一个缺失，整行被删。在缺失率高的数据集上，可能 80% 的行都被删了。

### 全部参数详解

```python
df.dropna(
    axis=0,         # 0=删行（默认）; 1=删列
    how='any',      # 'any'=有任意一个 NaN 就删（默认）; 'all'=整行/列全 NaN 才删
    thresh=3,       # "非空数" < 3 才删（更细粒度的控制）
    subset=['age'], # 只看这几列的 NaN 才决定删/不删（其他列的 NaN 忽略）
    inplace=False   # 是否原地修改（不推荐用 True，看下面陷阱）
)
```

### 4 个最常用的姿势

```python
# 姿势 1：删 NaN 比例 > 50% 的列
threshold = len(df) * 0.5
df.dropna(axis=1, thresh=threshold)
# 解释：thresh=N 意思是"至少要有 N 个非空才保留"
# 所以 thresh=len(df)*0.5 = "至少一半非空才保留" = "缺失 > 50% 就丢"

# 姿势 2：只看某几列，决定是否删行
df.dropna(subset=['age', 'income'])
# 只要 age 或 income 有缺失就删行；其他列缺失不管

# 姿势 3：删"全行都是 NaN"的行（罕见但偶尔有）
df.dropna(how='all')

# 姿势 4：目标列缺失，整行弃用
df = df.dropna(subset=['target'])   # ML 项目常做的预处理
```

### 一个真实例子

泰坦尼克号项目里你做过：

```python
df = df.drop(columns=['deck'])    # ← 你写的
# 等价于
df = df.dropna(axis=1, thresh=int(len(df) * 0.3))
# "保留至少 30% 非空的列" → deck 77% 缺失，会被丢弃
```

`drop` 是手动指定列名；`dropna` 是按规则批量。**有规则用 dropna，没规则用 drop**。

## 第 4 步 B：填充 (`fillna`)

### 4 种填充策略

#### 策略 1：固定值

```python
df['age'].fillna(0)              # 全填 0
df['name'].fillna('Unknown')     # 字符串列填"Unknown"
df.fillna(0)                     # 整表所有 NaN 填 0（粗暴，少用）
```

#### 策略 2：统计量（数值列最常用）

```python
df['age'].fillna(df['age'].mean())      # 用均值
df['age'].fillna(df['age'].median())    # 用中位数（推荐，对离群值不敏感）
df['gender'].fillna(df['gender'].mode()[0])  # 用众数（字符串列）
```

> **`.mode()[0]` 的怪写法**：`mode()` 可能返回**多个**最常见值（并列时），所以返回 Series。`[0]` 是取第一个。**当作固定语法记**。

#### 策略 3：按列分别填（字典语法）

```python
df.fillna({
    'age': df['age'].median(),
    'gender': 'Unknown',
    'income': 0,
    'score': df['score'].mean()
})
# 一行搞定多列各填各的
```

**这是实战中最优雅的写法**——一目了然每列的策略。

#### 策略 4：邻近值（时间序列专用）

```python
df['temp'].fillna(method='ffill')   # forward fill：用前一个非空值填
df['temp'].fillna(method='bfill')   # backward fill：用后一个非空值填
# 新版语法
df['temp'].ffill()
df['temp'].bfill()
```

**适用场景**：

```
时间    temp
10:00   20.5
10:05   NaN     ← ffill 后：20.5（用 10:00 的）
10:10   21.0
10:15   NaN     ← ffill 后：21.0（用 10:10 的）
10:20   21.5
```

传感器/股票等"短时间内变化不大"的数据，前向填充比"均值"合理。

#### 策略 5：插值（更精细的时间序列）

```python
df['temp'].interpolate(method='linear')   # 线性插值
df['temp'].interpolate(method='time')     # 按时间间隔插值
```

```
时间    temp     interpolate (linear)
10:00   20.0     20.0
10:05   NaN  →   21.0   ← 不是用 20.0 复制，是用 (20+22)/2 算出来
10:10   22.0     22.0
```

比 ffill 更"光滑"，但只对**真的有连续性**的数据有意义。

### 全部参数详解

```python
df.fillna(
    value=0,              # 要填什么（可以是标量、字典、Series、DataFrame）
    method=None,          # 'ffill' / 'bfill'（和 value 二选一）
    axis=None,            # 沿哪个轴填（method 模式下用）
    limit=None,           # 最多连续填几个（防止填太多失真）
    inplace=False
)
```

## 6 个常见陷阱

### 陷阱 1：以为 `== NaN` 能判断

```python
df[df['age'] == np.nan]   # ❌ 永远返回 0 行
df[df['age'].isna()]      # ✅ 正确
```

**记**：判断 NaN 永远用 `.isna()`，不用 `==`。

### 陷阱 2：`fillna` 不会改原 df

```python
df['age'].fillna(0)
print(df.isna().sum())   # age 列还是有缺失！

# 修复：重新赋值
df['age'] = df['age'].fillna(0)
# 或
df['age'].fillna(0, inplace=True)   # 不推荐
```

**记**：Pandas 大部分方法**返回新对象**，不改原 df。必须接收返回值或重新赋值。

### 陷阱 3：`dropna` 删过多导致样本数暴跌

```python
df.shape    # (1000, 20)
df.dropna()
df.shape    # (12, 20)    ← 只剩 12 行！
```

任意列有一个 NaN 整行就被删。20 列里只要每列缺失率有 20%，叠加起来很快删光。

**修复**：用 `subset` 限制范围，或者先填值再删：

```python
df.dropna(subset=['target'])   # 只看 target 列
# 或先填非关键列再删
df['notes'] = df['notes'].fillna('')
df.dropna(subset=['age', 'income'])
```

### 陷阱 4：用 `mean` 填 → 分布失真

```python
df['age'].fillna(df['age'].mean())
```

听起来合理，但**等价于把所有不知道年龄的人都设为同一个值**。如果缺失了 20%，分布的峰会变得很尖（人为堆积在均值上）。

**更稳的做法**：
- 用 `median`（不那么受离群值影响）
- 或按"组内均值"填（比如分性别填年龄均值）

```python
df['age'] = df['age'].fillna(df.groupby('gender')['age'].transform('median'))
# 男性缺失填男性中位数、女性缺失填女性中位数
```

### 陷阱 5：忘了 NaN 在 int 列变 float

```python
df['count'].dtype      # int64
df['count'].fillna(0)  # 但如果原来含 NaN，dtype 已经是 float64

# 想保持 int：fillna 后强制转回
df['count'] = df['count'].fillna(0).astype(int)
```

**为什么**：NumPy 的 int 类型**不支持** NaN（NaN 是 IEEE 754 float 标准的概念）。只要列含 NaN，自动升级成 float64。

### 陷阱 6：填充时机错误

```python
# ❌ 错：在 train 集上算均值，但用 train+test 一起的均值填
mean_age = df_all['age'].mean()
df_train['age'].fillna(mean_age)

# ✅ 对：只用 train 集的均值填 train 和 test
mean_age = df_train['age'].mean()
df_train['age'].fillna(mean_age)
df_test['age'].fillna(mean_age)
```

**为什么**：测试集是"未来未知数据"——你不应该用它的统计量影响训练。这叫**数据泄漏 (data leakage)**，是 ML 工程的大坑。

## 实战模板（你以后会反复用）

### 模板 1：拿到数据后的标准探索

```python
# Step 1: 看一眼
print(f'形状: {df.shape}')
print(df.dtypes)
df.head()

# Step 2: 缺失值全景
missing = pd.DataFrame({
    '缺失数': df.isna().sum(),
    '缺失比例(%)': (df.isna().mean() * 100).round(1)
})
missing = missing[missing['缺失数'] > 0].sort_values('缺失数', ascending=False)
print(missing)
```

### 模板 2：分门别类处理

```python
# 删缺失 > 70% 的列
threshold = len(df) * 0.3
df = df.dropna(axis=1, thresh=threshold)

# 数值列：用中位数填
for col in df.select_dtypes(include='number').columns:
    df[col] = df[col].fillna(df[col].median())

# 字符串列：用众数填（或 "Unknown"）
for col in df.select_dtypes(include='object').columns:
    df[col] = df[col].fillna(df[col].mode()[0] if not df[col].mode().empty else 'Unknown')

# 目标列（如果有缺失，直接删行）
df = df.dropna(subset=['target'])
```

### 模板 3：时间序列（短间隔变化不大）

```python
# 用 ffill，但限制最多连续填 3 个（防止长缺失填出离谱值）
df['temp'] = df['temp'].ffill(limit=3)

# 剩下的连续缺失太长，弃这些行
df = df.dropna(subset=['temp'])
```

### 模板 4：按组填充（更"贴近真实"的均值）

```python
# 缺失值用"同组的中位数"填，比全局均值更准
df['salary'] = df['salary'].fillna(
    df.groupby('department')['salary'].transform('median')
)
```

## 自检练习

```python
df = pd.DataFrame({
    'A': [1, 2, np.nan, 4, 5],
    'B': [np.nan, np.nan, 3, np.nan, 5],
    'C': ['x', np.nan, 'y', 'z', np.nan]
})
```

回答下面 4 个问题（不看答案）：

1. `df.isna().sum()` 输出什么？
2. `df.dropna()` 后还剩几行？
3. `df['B'].fillna(df['B'].mean())` 把 NaN 填成什么数字？
4. `df.dropna(thresh=2)` 后还剩几行？

<details>
<summary>展开看答案</summary>

**1.** 每列缺失数：
```
A    1
B    3
C    2
```

**2.** **只剩 1 行**（index=3 的行，但 B 是 NaN, C 是 'z'——等等让我重看）。

重新检查：
- row 0: B=NaN → 删
- row 1: B=NaN, C=NaN → 删
- row 2: A=NaN → 删
- row 3: B=NaN → 删
- row 4: C=NaN → 删

所以 `dropna()` 默认删任意含 NaN 的行，**5 行全删，剩 0 行**。

**3.** `df['B'].mean()` = (3 + 5) / 2 = **4.0**。NaN 都填 4.0。

**4.** `thresh=2` = "非空数 ≥ 2 才保留"。
- row 0: A=1, C='x'（B 是 NaN）→ 非空数 2，**保留**
- row 1: A=2（B、C 都 NaN）→ 非空数 1，删
- row 2: B=3, C='y'（A 是 NaN）→ 非空数 2，保留
- row 3: A=4, C='z'（B 是 NaN）→ 非空数 2，保留
- row 4: A=5, B=5（C 是 NaN）→ 非空数 2，保留

**剩 4 行**。

</details>

如果第 4 题答错了——`thresh` 的语义是初学者最容易翻车的点。**记死："至少有 thresh 个非空才保留"**。
