## ① 表合并：concat / merge / join（重头戏）

> 真实工作里**数据永远在多张表里**——用户表、订单表、商品表，要分析就得"拼起来"。Day04 教 3 种拼接工具。

### 三个 API 各管什么场景

```
concat   ── "上下叠 or 左右贴"，按位置硬拼，类似 SQL UNION
merge    ── 按"某列共同的值"配对拼，类似 SQL JOIN  ← 最常用
join     ── merge 的"按 index 简化版"
```

### 视频 01-02：concat 系列

- **01 concat 连接 Series**：把多个 Series 上下/左右拼成一个新 Series 或 DataFrame
- **02 concat 连接 DataFrame**：同上，DataFrame 版

**核心参数**：

```python
pd.concat([df1, df2], axis=0)   # 上下叠（行方向）← 默认
pd.concat([df1, df2], axis=1)   # 左右贴（列方向）
```

### 视频 03-06：merge 系列（**重点中的重点**）

- **03 merge 连接的方式**：基本用法 `df1.merge(df2, on="key")`
- **04 设置关联列以及通过索引关联**：`left_on / right_on / left_index / right_index`
- **05 join 通过索引连接**：`df.join(...)` 是按 index 的 merge 简化版
- **06 merge 连接方式的指定**：`how='inner' / 'left' / 'right' / 'outer'`

**核心套路**：

```python
df1.merge(df2, on='user_id', how='left')
#         │     │              │
#         │     │              └─ 4 种连接方式（最难理解的部分，必须懂）
#         │     └─ 用哪一列做"配对依据"
#         └─ 要拼接的另一张表
```

**4 种 `how` 一定要分清**（**重点掌握**）：

| how | 行为 | 类比 |
|---|---|---|
| `inner` | 只保留**两边都有**的 key 的行 | SQL INNER JOIN |
| `left` | 保留**左表全部**，右表没匹配的填 NaN | SQL LEFT JOIN（最常用）|
| `right` | 保留**右表全部** | SQL RIGHT JOIN（较少用）|
| `outer` | **两边全部都保留**，缺的填 NaN | SQL FULL OUTER JOIN |

> 🔥 **难点预警**：`merge` 是 Pandas 里数据处理最容易出错的 API。视频里一定要看清楚每种 `how` 的结果**有几行、缺失列怎么填**。卡住就让我拆。

### iOS 类比

```swift
// Swift 没有像 merge 那么强的内建 API，但概念类似：
let merged = users.compactMap { user in
    orders.first { $0.userId == user.id }.map { (user, $0) }
}
// = inner merge

// outer merge 在 Swift 里得自己写循环，所以 Pandas merge 真的是节省巨大
```

## ② 缺失值处理（你已经摸过，这里系统化）

视频 08-11 是 Pandas 缺失值的**4 步完整流程**：

| 视频 | API | 你做的事 |
|---|---|---|
| 08 **判断** | `isna() / isnull() / notna()` | "哪些是缺失" |
| 09 **查看** | `df.isna().sum()` 等 | "总共缺多少" |
| 10 **剔除** | `dropna(...)` | "缺的行/列直接丢" |
| 11 **填充** | `fillna(value)` | "缺的位置填上具体值" |

### 你需要新学的点（前面没摸过）

```python
# 1. isna vs isnull —— 完全一样（两个名字一个功能）
df.isna()      # ←推荐
df.isnull()    # ←别名，等价

# 2. NaN 在不同 dtype 里的不同表现
np.nan      # 数值列的 NaN
None        # object 列的"空"
pd.NaT      # 日期列的 NaT

# 3. dropna 的细控参数
df.dropna(axis=0)          # 删有 NaN 的"行"（默认）
df.dropna(axis=1)          # 删有 NaN 的"列"
df.dropna(how='all')       # 整行/列都是 NaN 才删
df.dropna(thresh=3)        # 非空数 < 3 才删
df.dropna(subset=['age'])  # 只看 age 列是否缺

# 4. fillna 的多种填充策略
df.fillna(0)                       # 全填 0
df.fillna({'age': 18, 'sex': 'M'}) # 按列分别填
df.fillna(method='ffill')          # 用前一个值填（时间序列常用）
df.fillna(method='bfill')          # 用后一个值填
df['age'].fillna(df['age'].mean()) # 用统计量填
```

**和泰坦尼克号的连接**：你之前 `df['age'].fillna(df['age'].mean())` 用过，这里是把它扩展成"4 步完整体系"。

## ③ apply / 向量化函数（灵活变换）

视频 12-14 教"**怎么对每一行 / 每一列 / 每个元素应用自定义函数**"。

### 视频 12-13：apply（Series 和 DataFrame 两种用法）

```python
# Series 上 apply：对每个元素跑一遍 func
df['age'].apply(lambda x: x * 2)
df['name'].apply(str.upper)

# DataFrame 上 apply：对每一行（默认）跑 func
df.apply(lambda row: row['age'] + row['fare'], axis=1)
#                                              ↑
#                                       axis=1 = 按行
df.apply(lambda col: col.mean(), axis=0)
#                                ↑
#                          axis=0 = 按列（默认）
```

### 视频 14：向量化函数

**重要概念**：`apply` 是"对每个元素跑一次 Python 函数"——**慢**。如果能用向量化操作（NumPy 算子或 Pandas 内置）就别用 apply：

```python
# ❌ 慢：apply
df['age2'] = df['age'].apply(lambda x: x * 2)

# ✅ 快得多：向量化
df['age2'] = df['age'] * 2
```

**记忆口诀**：
- **能用向量化（`+`, `*`, `>`, `.str`, `.dt`）就用** → 内部 C 实现，秒级
- **真的非要写复杂逻辑** → 才用 `apply` → 单元素调 Python，可能慢百倍

> 这个观念对你以后做大数据处理至关重要——10 万行 apply 慢半分钟、向量化 0.1 秒。**性能差距 = 100 倍**。

## ④ groupby 进阶（你刚学完核心，这里补"花式用法"）

> 你刚在 P05_Weather 把 groupby 核心理解透了——"作用域开关 + split-apply-combine"。这一节 4 个视频教 4 种**进阶聚合形态**。

### 视频 15：分组聚合（基础回顾）

```python
df.groupby("col").mean()    # 你已经会
```

### 视频 16：`cut` 函数（**新内容**）

**`cut` 是"把连续数值切成区间"**——常和 groupby 配合用。

```python
# 把 age 切成 4 个年龄段
df['age_group'] = pd.cut(df['age'], bins=[0, 18, 35, 60, 100],
                                    labels=['少年', '青年', '中年', '老年'])

# 然后按这个新列分组
df.groupby('age_group')['fare'].mean()
```

**应用场景**：
- 把"年龄"切成"少年/青年/中年/老年"
- 把"收入"切成"低/中/高"分位
- 任何"连续数值 → 离散分组"的特征工程

类似函数：**`qcut`**——按分位数切（每段人数相等，而不是每段宽度相等）。

### 视频 17：`agg` 聚合（**重点**）

你已经在 groupby系统理解.md 看过这个。**一次出多种统计**：

```python
df.groupby("year")["temp_max"].agg(["mean", "max", "std"])
df.groupby("year").agg({
    "temp_max": "mean",
    "wind":     ["mean", "max"]
})
```

### 视频 18：分组转换和过滤（**新内容**，重要）

- **`transform`**：聚合后**广播回每一行**（不像 agg 把组压成一行）
- **`filter`**：按"组的条件"决定**保留/丢弃整个组**

```python
# transform：算每行所属年份的平均温度，加回每行
df['year_avg'] = df.groupby('year')['temp_max'].transform('mean')

# filter：只保留"行数 > 360"的年份（满 1 年的）
df.groupby('year').filter(lambda g: len(g) > 360)
```

**transform 的经典用途**：**去中心化**（每行减去所在组的均值）：

```python
df['temp_max_centered'] = df['temp_max'] - df.groupby('month')['temp_max'].transform('mean')
```

这种"组内标准化"在 ML 特征工程里**极其常见**。

## 速查 API 表

| API | 一句话 |
|---|---|
| `pd.concat([df1, df2], axis=0/1)` | 上下叠 / 左右贴 |
| `df1.merge(df2, on=..., how=...)` | 按值关联（最重要）|
| `df1.join(df2, how=...)` | 按 index 关联（merge 简版）|
| `df.isna() / isnull()` | 哪些是 NaN |
| `df.dropna(...)` | 删 NaN 行/列 |
| `df.fillna(...)` | 填 NaN |
| `s.apply(func)` | 每元素跑 func |
| `df.apply(func, axis=...)` | 每行/每列跑 func |
| `pd.cut(s, bins=...)` | 连续值 → 离散区间 |
| `pd.qcut(s, q=...)` | 按分位数切 |
| `g.agg({...})` | 一次多统计 |
| `g.transform(func)` | 聚合后广播回每行 |
| `g.filter(func)` | 按组条件保留/丢组 |
