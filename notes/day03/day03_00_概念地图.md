## ① Series 速复习（P01）

Day02 学过的内容，这一节只是热身：

```python
s = pd.Series([10,20,30,40,50], index=['a','b','c','d','e'])

s.loc["a":"c"]    # 标签切片（闭区间）
s.iloc[1:4]       # 位置切片（左闭右开）
s[1:4]            # 默认 = iloc 的行为

# 布尔过滤（重点）
bools = s > s.mean()
s[bools]          # 只保留大于均值的元素
```

**就一个新认知点**：`s[bools]` 这种布尔过滤——它和 NumPy 的布尔索引完全一致，**Pandas 全程沿用**。Day04 的 `df[df['age']>18]` 是这个的扩展。

## ② DataFrame 全套（P02）—— **Day03 重头戏**

视频 P02 把 DataFrame 的 4 大主题 **一气讲完**：

```
DataFrame 是什么 → 怎么造  →  有什么属性  →  怎么改
       ↓             ↓            ↓             ↓
     概念        创建 4 法      属性 + 方法    增删改 4 法
```

### 2.1 创建方式（3 种）

```python
# 法 1：传 dict，key 当列名
pd.DataFrame({"name":["张三","李四"], "age":[10,20]})

# 法 2：dict of Series
pd.DataFrame({"Mango": mongo_series, "Apple": apple_series})

# 法 3：指定 columns 和 index（控制顺序）
pd.DataFrame({...}, columns=["age","name"], index=[100,200,300])
```

### 2.2 属性 + 方法（一大坨，但要全部脸熟）

| 类别 | API | 一句话 |
|---|---|---|
| **属性** | `df.index / columns / values / shape / dtypes / size / T` | 看 DataFrame 长什么样 |
| **取值** | `df.loc / iloc / at / iat` | 4 种取值器 |
| **预览** | `df.head() / tail() / sample()` | 看头尾 / 随机抽 |
| **统计** | `df.sum / mean / max / min / std / var / median / mode / quantile` | 9 个常用统计 |
| **总览** | `df.describe() / info()` | 一键看分布 / dtype |
| **去重** | `df.drop_duplicates() / unique() / value_counts() / nunique()` | 重复值四件套 |
| **空值** | `df.isna() / count()` | 数 NaN / 数非空 |
| **排序** | `df.sort_index() / sort_values() / nlargest() / nsmallest()` | 4 种排序 |
| **累计** | `df.cumsum() / cummax() / cummin() / cumprod() / diff()` | 5 个累计运算 |
| **比较** | `df.equals(df2) / isin([...])` | 整体相等 / 元素包含 |

> 看上去像一长串考点。**实战时记住每类一两个最常用的就行**：`describe`、`value_counts`、`sort_values`、`nlargest`、`isna`——其他用到时查。

### 2.3 布尔索引（**重点中的重点**）

```python
# 一行筛选
df[df["age"] > 25]

# 两步等价写法（看清原理时用这种）
bools = df["age"] > 25     # 等长 bool Series
df[bools]                  # 用 bool Series 过滤
```

🔥 **这是 Pandas 数据筛选的标准动作**——后面所有"洗数据"操作都基于它。

### 2.4 运算

```python
df * 2                 # 标量广播
df["age"] * 2          # 单列广播
df1 + df2              # 按 index 对位（对不上的填 NaN）
```

> 🔥 **第一个卡点预警**：`df1 + df2` 按 **index 对位**——这是 Pandas 和 NumPy 最大的不同。NumPy 按位置加，Pandas 按标签加。

### 2.5 增删改

```python
# 修改 index/columns 的 3 种方法
df.set_index("id")                            # 把某列设为行标签
df.reset_index()                              # 还原成默认 0..n-1
df.rename(index={...}, columns={...})         # 重命名
df.index = [...]; df.columns = [...]          # 直接赋值

# 增删列
df["new_col"] = [...]                         # 添加列
df.insert(0, "new_col", [...])                # 指定位置插入
df.drop("col", axis=1, inplace=True)          # 删列
df.drop(3, axis=0, inplace=True)              # 删行
del df["col"]                                 # 删列（Python 风格）
```

## ③ 导入导出（P03）

视频 P03 把 4 个常见落地场景一锅炖：

```
CSV ←→ DataFrame       (read_csv / to_csv)
JSON ←→ DataFrame      (read_json / to_json)
剪贴板 ←→ DataFrame    (read_clipboard / to_clipboard)
MySQL ←→ DataFrame     (read_sql / to_sql + sqlalchemy)
```

**关键参数**：

```python
df.to_csv("test.csv", encoding="gbk")               # 中文不乱码
df.to_json("test.json", force_ascii=False)          # 中文不变 \uXXXX

# MySQL（需要 pymysql + sqlalchemy）
engine = create_engine(f"mysql+pymysql://user:pwd@host:port/db?charset=utf8mb4")
df.to_sql("t_test", engine, if_exists="replace")
pd.read_sql("t_test", engine)
```

> **iOS 老兵的直觉**：DataFrame 和 SQL 表是 **数学上等价** 的——一组带列名、带 index 的二维表。所以 `to_sql` / `read_sql` 是最 "自然" 的接口。

## ④ 日期处理（P04）—— **小但极重要**

> 真实数据 90% 含时间字段，而 CSV 读进来的日期 **默认都是字符串**。`to_datetime` 是把它"变成日期类型"的入口。

### 两步走

```python
# 第 1 步：字符串 → datetime
df["ymd"] = pd.to_datetime(df["trade_date"])

# 第 2 步：用 .dt 访问器抽各种属性
df["yy"]    = df["ymd"].dt.year
df["mm"]    = df["ymd"].dt.month
df["dd"]    = df["ymd"].dt.day
df["week"]  = df["ymd"].dt.day_name()       # Monday/Tuesday/...
df["q"]     = df["ymd"].dt.quarter          # 1/2/3/4
df["mend"]  = df["ymd"].dt.is_month_end     # bool
df["yend"]  = df["ymd"].dt.is_year_end
```

### `.dt.to_period(...)` —— "归到某个时间桶"

```python
df["ystat"] = df["ymd"].dt.to_period("Y")   # 2023
df["mstat"] = df["ymd"].dt.to_period("M")   # 2023-12
df["qstat"] = df["ymd"].dt.to_period("Q")   # 2023Q4
df["wstat"] = df["ymd"].dt.to_period("W")   # 2023-12-25/2023-12-31
```

**用途**：把"具体日期"映射到"年/月/季/周"，**配合 groupby 做时间序列聚合的核心姿势**。

```python
# 你在 P05_Weather 用过的
df["month"] = pd.to_datetime(df["date"]).dt.to_period("M").astype(str)
df.groupby("month")[["temp_max","temp_min"]].mean()
```

## ⑥ 员工实战（P06）

`employees.csv` 在 Day04 视频里继续用，所以这里第一次见。Day03 的 P06 主要练这 5 个动作：

```python
df = pd.read_csv("employees.csv")

# 1. 找极值
df.nlargest(1, "salary")                          # 最高薪 1 个
df[df["salary"] == df["salary"].min()]            # 最低薪（布尔索引）

# 2. 排序变形
df.sort_values(by="salary", ascending=False).head(1)

# 3. 取唯一值
df["department_id"].unique()

# 4. 按部门统计
df.groupby("department_id")["employee_id"].count()

# 5. 一行出图
df.groupby("department_id")["employee_id"].count().plot(kind="bar")
```

**重点验证的能力**：把布尔索引、排序、groupby、可视化这些零散动作 **连起来用**——这才是真实数据分析的样子。

## 重点 vs 可跳

### ⭐⭐⭐ 必须掌握

- DataFrame 的 4 种取值器：`loc / iloc / at / iat`
- 布尔索引：`df[df["col"] > x]`
- `set_index` / `reset_index` / `rename` 三件套
- 日期：`pd.to_datetime` + `.dt.year/month/day` + `.dt.to_period`
- CSV 读写：`read_csv` / `to_csv` + 中文编码 `encoding="gbk"`

### ⭐⭐ 知道就行

- 累计运算 `cumsum / cummax / diff`（时间序列才常用）
- 统计九件套（`mean/std/var/...`，要时再查）
- JSON / MySQL 读写（SQL 不在 Pandas 重点上）

### ⭐ 用到再查

- `at` / `iat`（性能优化时用，平时 `loc/iloc` 够了）
- `mode()` / `quantile()`
- `equals` / `isin`

## 你看 day03 会撞到的"卡点"预测

1. **`loc` 是闭区间，`iloc` 是左闭右开** —— 切片时容易越界少一个
2. **`set_index` 之后列里没有原 index 列了** —— 不是消失，是变成索引
3. **`df1 + df2` 按 index 对位（不是按位置）** —— 第一次遇到会困惑结果为什么有 NaN
4. **`inplace=True` vs 链式调用** —— 视频里 `inplace=True` 改的是原表，没赋值的就走链式
5. **`pd.to_datetime` 是函数，`.dt` 是 Series 的访问器** —— 一个静态、一个动态

撞到任何一个**直接告诉我**，按 P05_Weather 的标准给 `.ipynb` 加 Claude 讲解 cell。

## 速查 API 表

| API | 一句话 |
|---|---|
| `pd.DataFrame({...}, columns=[...], index=[...])` | 创建 |
| `df.loc / iloc / at / iat` | 4 种取值器 |
| `df.head() / tail() / sample()` | 看局部 |
| `df.describe() / info()` | 一键概览 |
| `df.sort_values(by=[...], ascending=[...])` | 排序 |
| `df.nlargest(n, "col") / nsmallest(n, "col")` | 极值 n 行 |
| `df.value_counts() / unique() / nunique()` | 重复值三件套 |
| `df.isna() / count()` | NaN 计数 |
| `df.cumsum() / diff()` | 累计 / 差分 |
| `df.set_index() / reset_index() / rename()` | 改 index / 列名 |
| `df["col"] = ...` / `df.insert(...)` / `df.drop(...)` | 增删列/行 |
| `pd.read_csv / to_csv(encoding="gbk")` | CSV 读写 |
| `pd.read_json / to_json(force_ascii=False)` | JSON 读写 |
| `pd.read_sql / to_sql + sqlalchemy.create_engine` | MySQL 读写 |
| `pd.to_datetime(series)` | 字符串 → 日期 |
