## 为什么需要日期处理

CSV / 数据库 / API 拿到的日期字段，**默认都是字符串**：

```python
df = pd.DataFrame({
    "gmv": [100, 200, 300, 400],
    "trade_date": ["2025-01-06", "2023-10-31", "2023-12-31", "2023-01-05"]
})

df.dtypes
# gmv             int64
# trade_date     object   ← 是字符串！不是日期
```

字符串能干嘛？**几乎什么都不能干**：

```python
df["trade_date"].dt.year     # ❌ AttributeError: 字符串没有 .dt
df["trade_date"] < "2024-01-01"  # ⚠️ 字符串比较，靠字典序"碰巧"对（很危险）
df.groupby(df["trade_date"].dt.month).sum()   # ❌ 同样不行
```

**所以拿到带日期的数据，第一件事就是 `pd.to_datetime` 把它转成真正的日期类型**。

---

## 一句话定位

```
pd.to_datetime(...)       = "字符串 → 日期"的入口函数
series.dt.xxxx            = 日期 Series 的"属性访问器"，抽各种时间维度
series.dt.to_period(...)  = "归到某个时间桶"（年/月/季/周）
```

3 个工具配合，就能搞定 90% 时间字段分析。

---

## 第一部分：`pd.to_datetime` —— 字符串转日期

### 1.1 最简形态

```python
df["ymd"] = pd.to_datetime(df["trade_date"])

df.dtypes
# trade_date           object
# ymd          datetime64[ns]    ← 真正的日期类型
```

`datetime64[ns]` 是 NumPy 的"纳秒精度时间戳"——Pandas 内部用的标准日期格式。

### 1.2 支持的输入格式（**自动识别能力很强**）

```python
pd.to_datetime("2025-01-06")           # ISO 标准
pd.to_datetime("2025/01/06")           # 斜杠
pd.to_datetime("Jan 6, 2025")          # 英文
pd.to_datetime("06-Jan-2025")          # 反过来
pd.to_datetime("20250106")             # 纯数字
pd.to_datetime(1704499200, unit="s")   # Unix 时间戳（秒）
pd.to_datetime(1704499200000, unit="ms") # Unix 毫秒
```

🔥 **第一卡点**：当格式很怪 / 解析慢 / 解析错时，**显式指定 `format`**：

```python
# 自动猜测（10 万行可能慢 5 秒）
pd.to_datetime(df["date"])

# 显式指定（10 万行 < 1 秒）
pd.to_datetime(df["date"], format="%Y-%m-%d")
pd.to_datetime(df["date"], format="%Y/%m/%d %H:%M:%S")
```

**常用 format 符号**：

| 符号 | 含义 | 例 |
|---|---|---|
| `%Y` | 4 位年 | 2025 |
| `%y` | 2 位年 | 25 |
| `%m` | 月（01-12）| 01 |
| `%d` | 日（01-31）| 06 |
| `%H` | 小时（00-23）| 14 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 45 |

### 1.3 解析失败的处理

```python
# 默认：解析失败抛异常
pd.to_datetime(["2025-01-06", "garbage"])   # ❌ ParserError

# 软处理：失败的填 NaT（Not a Time）
pd.to_datetime(["2025-01-06", "garbage"], errors="coerce")
# DatetimeIndex(['2025-01-06', 'NaT'], ...)

# 忽略：失败保留原值
pd.to_datetime(["2025-01-06", "garbage"], errors="ignore")
```

**实战推荐**：处理脏数据用 `errors="coerce"`——失败的变 NaT，后面用 `isna()` 找出来再决定怎么办。

## 第二部分：`.dt` 访问器 —— 抽取时间维度

> 一旦列变成了 `datetime64`，`.dt` 这个**访问器对象**就解锁了一堆属性。

### 2.1 视频里的核心 7 个

```python
df = pd.DataFrame({
    "gmv": [100, 200, 300, 400],
    "trade_date": ["2025-01-06", "2023-10-31", "2023-12-31", "2023-01-05"]
})
df["ymd"] = pd.to_datetime(df["trade_date"])

df["yy"]      = df["ymd"].dt.year         # 2025
df["mm"]      = df["ymd"].dt.month        # 1
df["dd"]      = df["ymd"].dt.day          # 6
df["week"]    = df["ymd"].dt.day_name()   # Monday
df["quarter"] = df["ymd"].dt.quarter      # 1
df["mend"]    = df["ymd"].dt.is_month_end # False（不是月末）
df["yend"]    = df["ymd"].dt.is_year_end  # False（不是年末）
```

**输出**（部分）：

```
        ymd  yy  mm  dd      week  quarter   mend   yend
0 2025-01-06 2025  1   6    Monday        1  False  False
1 2023-10-31 2023 10  31   Tuesday        4   True  False
2 2023-12-31 2023 12  31    Sunday        4   True   True
3 2023-01-05 2023  1   5  Thursday        1  False  False
```

### 2.2 完整 `.dt` 属性大全

按"实战频率"分级：

#### ⭐⭐⭐ 必会

```python
.dt.year       # 年（4 位）
.dt.month      # 月（1-12）
.dt.day        # 日（1-31）
.dt.hour       # 时
.dt.minute     # 分
.dt.second     # 秒
.dt.weekday    # 周几（0=Mon, 6=Sun）
.dt.day_name() # 周几名字（Monday...）
.dt.quarter    # 季度（1-4）
.dt.dayofyear  # 一年中的第几天（1-366）
```

#### ⭐⭐ 常用

```python
.dt.is_month_start    # 是否月初
.dt.is_month_end      # 是否月末
.dt.is_quarter_start  # 是否季初
.dt.is_quarter_end    # 是否季末
.dt.is_year_start     # 是否年初
.dt.is_year_end       # 是否年末
.dt.is_leap_year      # 是否闰年
.dt.days_in_month     # 当月有几天
```

#### ⭐ 偶尔用

```python
.dt.week       # ISO 周数
.dt.date       # 只取日期部分（去掉时分秒）
.dt.time       # 只取时间部分
.dt.normalize()  # 把时分秒清零
```

### 2.3 `.dt` 是什么 —— 它是个"访问器对象"

🔥 **关键认知**：

```python
df["ymd"].dt       # ← 这本身不是属性，是个"访问器对象"
df["ymd"].dt.year  # ← 通过它才能拿到 year
```

**类比**：

| 对象 | 访问器 | 例子 |
|---|---|---|
| 日期 Series | `.dt` | `s.dt.year` |
| 字符串 Series | `.str` | `s.str.upper()` / `s.str.contains("xx")` |
| 类别 Series | `.cat` | `s.cat.categories` |

🔥 **关键限制**：访问器只对对应类型有效。

```python
df["trade_date"].dt.year   # ❌ 报错！trade_date 还是字符串
df["ymd"].dt.year          # ✅ ymd 是 datetime64
```

→ **永远先 `pd.to_datetime` 转类型，再用 `.dt`**。

## 第三部分：`dt.to_period` —— 归到时间桶

### 3.1 为什么需要 period

直接的 `datetime` 是"**具体一秒**"——`2023-10-31 15:42:18`，**精确度太高**反而无法分组。

**典型场景**：你有 1000 条订单时间戳，想按"月"统计总额。直接 `groupby` 时间戳——每个时间戳都不一样，每组只有 1 个！

→ 需要把"具体时间"映射到"它所在的月"——这就是 `to_period`。

### 3.2 视频例子

```python
df["ystat"] = df["ymd"].dt.to_period("Y")   # 2025
df["mstat"] = df["ymd"].dt.to_period("M")   # 2025-01
df["qstat"] = df["ymd"].dt.to_period("Q")   # 2025Q1
df["wstat"] = df["ymd"].dt.to_period("W")   # 2025-01-06/2025-01-12
```

**输出**：

```
        ymd  ystat    mstat   qstat                  wstat
0 2025-01-06  2025  2025-01  2025Q1  2025-01-06/2025-01-12
1 2023-10-31  2023  2023-10  2023Q4  2023-10-30/2023-11-05
2 2023-12-31  2023  2023-12  2023Q4  2023-12-25/2023-12-31
3 2023-01-05  2023  2023-01  2023Q1  2023-01-02/2023-01-08
```

### 3.3 `to_period` 的参数

```python
.dt.to_period("Y")    # 年
.dt.to_period("Q")    # 季度（按自然季）
.dt.to_period("M")    # 月
.dt.to_period("W")    # 周（默认周日开始）
.dt.to_period("D")    # 日（一般用不到）
.dt.to_period("H")    # 时
```

### 3.4 `period` 是个什么类型

```python
df["mstat"].dtype
# period[M]   ← Pandas 自有的"周期类型"
```

它**不是字符串**。看着像 `"2023-10"`，实际是个 Period 对象，所以仍可以参与计算（比如比较大小、加减月数）。

**通常实战做法**：转成字符串当 groupby 的 key 更稳：

```python
df["month"] = df["ymd"].dt.to_period("M").astype(str)
# 现在 month 列是 "2023-10" 这种字符串
df.groupby("month")["gmv"].sum()
```

### 3.5 与 P05_Weather 的串联

你在 P05_Weather 写过：

```python
df["month"] = pd.to_datetime(df["date"]).dt.to_period("M").astype(str)
df.groupby("month")[["temp_max","temp_min"]].mean()
```

**逐句拆解**：

```
pd.to_datetime(df["date"])
    ↓ 字符串 → datetime64
.dt.to_period("M")
    ↓ datetime64 → period[M]  ("2023-10")
.astype(str)
    ↓ period → str            ("2023-10" 字符串)
df.groupby("month")[...].mean()
    ↓ 按月分组求均值
```

整个链路 **3 个转换 + 1 个聚合**——这就是真实数据分析的标准动作。

## 第四部分：日期运算

### 4.1 时间差（Timedelta）

```python
s1 = pd.to_datetime(["2025-01-06", "2025-01-10"])
s2 = pd.to_datetime(["2025-01-01", "2025-01-05"])

s1 - s2
# TimedeltaIndex(['5 days', '5 days'], ...)
```

**Timedelta 也有 `.dt` 访问器**：

```python
diff = s1 - s2
diff.days       # ndarray: [5, 5]
diff.total_seconds()    # 秒数
```

### 4.2 日期 ± 时间差

```python
df["ymd"] + pd.Timedelta(days=7)        # 加 7 天
df["ymd"] - pd.Timedelta(hours=3)        # 减 3 小时

# 加月数要用 DateOffset（月长不一样）
df["ymd"] + pd.DateOffset(months=1)
```

### 4.3 生成日期序列

```python
pd.date_range(start="2025-01-01", end="2025-01-10")
# DatetimeIndex(['2025-01-01', '2025-01-02', ..., '2025-01-10'])

pd.date_range(start="2025-01-01", periods=10, freq="D")  # 10 天
pd.date_range(start="2025-01-01", periods=12, freq="ME")  # 12 个月末
pd.date_range(start="2025-01-01", periods=52, freq="W")  # 52 周
```

**用途**：造测试数据 / 补齐缺失日期 / 时间序列预测的索引。

## 第五部分：时区（高阶，了解即可）

```python
ts = pd.to_datetime("2025-01-06 12:00:00")
ts_utc = ts.tz_localize("UTC")            # 标记为 UTC
ts_sh = ts_utc.tz_convert("Asia/Shanghai")  # 转上海时区
```

**实战提醒**：处理跨时区数据（比如 AWS 日志 vs 国内业务），**永远显式声明时区**——否则会有"差 8 小时"的诡异 bug。

## 卡点汇总（4 大坑预警）

1. **`pd.to_datetime` 是函数，`.dt` 是访问器** —— `pd.to_datetime(s).dt.year` 而不是 `s.dt.year`（前提是 s 还是字符串）
2. **字符串列不能用 `.dt`** —— 必须先 `pd.to_datetime` 转类型
3. **`to_period("M")` 返回 Period 不是 string** —— groupby 时通常 `.astype(str)` 一下更稳
4. **`format` 写错会静默猜测出错** —— 大文件用 `format=...` 既快又稳

## 自测题（请合上笔记复述）

> 给你 `df = pd.DataFrame({"order_id":[1,2,3], "ts":["2024-03-15 10:30","2024-03-15 14:20","2024-03-16 09:15"], "amount":[100,200,300]})`，完成：
>
> 1. 把 `ts` 转成日期类型
> 2. 抽出"周几"和"小时"两列
> 3. 按"年-月-日"分组求每天的总金额
> 4. 找出在月末下单的所有记录

<details>
<summary>👇 答案展开</summary>

```python
import pandas as pd

df = pd.DataFrame({
    "order_id": [1, 2, 3],
    "ts": ["2024-03-15 10:30", "2024-03-15 14:20", "2024-03-16 09:15"],
    "amount": [100, 200, 300]
})

# 1. 转日期
df["ts"] = pd.to_datetime(df["ts"])

# 2. 抽属性
df["weekday"] = df["ts"].dt.day_name()
df["hour"] = df["ts"].dt.hour

# 3. 按日期分组求和
df["date"] = df["ts"].dt.date
df.groupby("date")["amount"].sum()
# 或者
df.groupby(df["ts"].dt.to_period("D"))["amount"].sum()

# 4. 月末记录
df[df["ts"].dt.is_month_end]
```
