## P05 · 天气数据实战（已学透，做"快速验证"）

> 你已经知道全部逻辑，这一段就当 **复习题** 自检。

### 数据：`weather.csv` (1461 行 × 6 列)

```
date         precipitation  temp_max  temp_min  wind  weather
2012-01-01   ...            12.8      5.0       4.7   drizzle
2012-01-02   ...            10.6      2.8       4.5   rain
...
```

### 6 步走通

```python
import pandas as pd

# 1. 读入
df = pd.read_csv("weather.csv")

# 2. 看长相
df.shape            # (1461, 6)
df.head()
df.dtypes           # date 是 object（字符串）

# 3. 看分布
df.describe()
df.info()

# 4. 清洗（这一步 P05 没特别做，因为数据干净）
df["month"] = pd.to_datetime(df["date"]).dt.to_period("M").astype(str)
df["year"]  = pd.to_datetime(df["date"]).dt.year

# 5. 分析（4 个标准动作）
# (a) 选列
df[["date", "temp_max", "temp_min"]]

# (b) 取行
df.loc[[1, 10, 100], ["temp_max", "temp_min"]]
df.iloc[:10, 2:6]

# (c) 排序 / 极值
df.nlargest(30, "temp_max")                                   # 最热的 30 天
df.nlargest(30, "temp_max").nsmallest(5, "temp_min")          # 链式：从最热 30 天里挑最冷的 5 天

# (d) 分组聚合
df.groupby("month")[["temp_max", "temp_min"]].mean()          # 每月均温
df.groupby("month")["weather"].nunique()                      # 每月几种天气

# 6. 出图
df.groupby("month")[["temp_max","temp_min"]].mean().plot()
```

### 经典题：**找出每年的最高温度**

视频里给了 **两种写法**——对比着学：

```python
# 写法 A：groupby + max（简洁）
df["year"] = pd.to_datetime(df["date"]).dt.year
df.groupby("year")["temp_max"].max()

# 写法 B：sort + drop_duplicates（保留完整行）
year_sort = df.sort_values(by=["year","temp_max"], ascending=[True, False])
year_sort.drop_duplicates(subset=["year"])
# 输出：每年最热那天的"完整行"——日期/降水/风速都在
```

**两种写法的区别**：

| 写法 | 结果 | 何时用 |
|---|---|---|
| A: `groupby.max()` | **只有 year + max(temp)** 两列 | 只想要那个数 |
| B: `sort + drop_duplicates` | **完整的最热那天** 一行 | 想知道是哪天、当天还有什么数据 |

🔥 **这是真实分析里常见的取舍**——别只学一种，两种都要会。

## P06 · 员工数据实战（**重点**）

> 第一次见 `employees.csv`，这数据集在 Day04 还会反复用。

### 数据：`employees.csv` (107 行 × 10 列)

关键列：

```
employee_id  first_name  last_name  email  phone_number
job_id       salary      commission_pct
manager_id   department_id  hire_date
```

### 6 步走通

```python
import pandas as pd
df = pd.read_csv("employees.csv")

# 1. 看长相
df.shape           # (107, 10) — 107 个员工
df.head()
df.dtypes
df.info()          # department_id 有 NaN（顶层 CEO 没有 department）
```

### 5.1 找极值的 3 种写法（**核心练习**）

```python
# 写法 A：布尔索引（最直观）
df[df["salary"] == df["salary"].max()]       # 最高薪员工
df[df["salary"] == df["salary"].min()]       # 最低薪员工

# 写法 B：loc 显式（和 A 等价，更显式）
df.loc[df["salary"] == df["salary"].max()]

# 写法 C：排序后取头尾
df.sort_values(by="salary", ascending=False).head(1)   # 最高薪
df.sort_values(by="salary", ascending=False).tail(1)   # 最低薪

# 写法 D：nlargest / nsmallest（**最佳，最快**）
df.nlargest(1, "salary")
df.nsmallest(1, "salary")
df.nlargest(10, "salary")   # 取前 10
```

🔥 **4 种写法的优劣**：

| 写法 | 优 | 劣 |
|---|---|---|
| A 布尔索引 | 直观、可加多条件 | 要遍历两次（先 max 后比较）|
| C 排序 | 灵活、可取多个 | 排序 O(n log n)，浪费 |
| D nlargest | **O(n)，最快** | 只能按一列 |

**实战推荐**：`df.nlargest(n, "col")` —— 找极值就用它。

### 5.2 唯一值 / 计数

```python
# 部门有哪些（去重）
df["department_id"].unique()
# array([90., 60., 100., 30., 50., 80., 10., 20., 70., 110., 40., nan])

# 每个部门多少人
df.groupby("department_id")["employee_id"].count()
# 10.0       1
# 20.0       2
# 30.0       6
# 50.0      45
# 80.0      34
# 90.0       3
# ...
```

🔥 **第一卡点**：注意 `nan` —— 有员工 `department_id` 是 NaN（CEO 不属于任何部门）。`groupby` 会**自动忽略 NaN 组**——这 1 个员工不在统计里。要包含进来用 `dropna=False`：

```python
df.groupby("department_id", dropna=False)["employee_id"].count()
# NaN 也会作为一个组出现
```

### 5.3 出图（条形图）

```python
df.groupby("department_id")["employee_id"].count() \
  .rename("employee_count") \
  .plot(kind="bar")
```

**链式解读**：

```
df.groupby("department_id")        ← 按部门分组
  ["employee_id"]                  ← 选这一列
  .count()                         ← 数每组多少行 → Series
  .rename("employee_count")        ← 给 Series 起个名（图的 Y 轴标签会用）
  .plot(kind="bar")                ← 画条形图
```

### 5.4 平均薪资最高的部门

```python
df.groupby("department_id")["salary"].mean().nlargest(1)
# department_id
# 90.0    19333.333333    ← 90 部门（高管层）平均薪资最高
```

**链式解读**：

```
df.groupby("department_id")["salary"]    ← 按部门分组，选 salary
  .mean()                                 ← 每部门求均值 → 11 行 Series
  .nlargest(1)                            ← 找均值最大的那 1 行
```

这是个 **极其常见的分析模板**："按 X 分组算 Y 的均值，找最高/最低的 N 个"。

### 5.5 综合分析示例（**自己写一遍**）

```python
# 题：哪个部门的"薪资标准差"最大（即"薪资差距最大"的部门）？
df.groupby("department_id")["salary"].std().nlargest(1)

# 题：薪资中位数 > 10000 的部门
result = df.groupby("department_id")["salary"].median()
result[result > 10000]

# 题：部门人数 > 5 且平均薪资 > 8000 的部门
g = df.groupby("department_id")
result = g.agg(count=("employee_id","count"), avg=("salary","mean"))
result[(result["count"] > 5) & (result["avg"] > 8000)]
```

## 常见的"卡住"模式（4 个典型）

1. **`g.mean()` 结果和 df 长度对不上** —— 想加回 df 当一列要用 `transform`，不是 `mean`
2. **链式调用结果"莫名其妙的多了一列"** —— 通常是 reset_index 没做，或者 unstack 把组变成了列
3. **`groupby` 后丢了 NaN 组** —— 默认行为，需要时加 `dropna=False`
4. **画图不显示中文** —— matplotlib 默认字体不含中文，要 `plt.rcParams['font.sans-serif'] = ['SimHei']`
