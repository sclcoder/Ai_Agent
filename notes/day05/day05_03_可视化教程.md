## 第一部分：matplotlib 基础（P03）

### 1.1 安装 + 中文

```python
import matplotlib.pyplot as plt
from matplotlib import rcParams

# 中文显示（解决"方块字"问题）
rcParams["font.sans-serif"] = ["SimHei"]    # 黑体（Windows / Mac 都有）
# rcParams["font.sans-serif"] = ["KaiTi"]    # 楷体
# rcParams["font.sans-serif"] = ["Arial Unicode MS"]   # Mac 自带

# 解决负号"-"显示问题
rcParams["axes.unicode_minus"] = False
```

🔥 **第一卡点**：matplotlib 默认字体不含中文 → **所有中文都变方块**。永远第一行加 `rcParams` 设字体。

### 1.2 两种使用风格

#### 风格 A：`plt.xxx`（脚本风格）

视频里第一个例子用的就是这种：

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

plt.figure(figsize=(10, 6))           # 创建画布

plt.subplot(2, 1, 1)                   # 2 行 1 列，操作第 1 个
plt.xlim(0, 10)
plt.ylim(-1, 1)
plt.xlabel('x'); plt.ylabel('sin(x)'); plt.title('sin')
plt.plot(x, y1)

plt.subplot(2, 1, 2)                   # 操作第 2 个
plt.xlim(0, 10); plt.ylim(-1, 1)
plt.xlabel('x'); plt.ylabel('cos(x)'); plt.title('cos')
plt.plot(x, y2)
```

🔥 **这种写法的问题**：

- 看不出当前在操作哪个子图（`plt.xxx` 是"全局当前"）
- 多图嵌套容易乱
- 不能保存子图对象做高级操作

#### 风格 B：`fig / ax`（面向对象，**推荐**）

视频里第二个例子用了这种，**专业实战首选**：

```python
fig, ax = plt.subplots(2, figsize=(10, 6))    # 2 个子图

ax[0].plot(x, y1)
ax[0].set_xlim(0, 10)
ax[0].set_ylim(-1, 1)
ax[0].set_xlabel("x")
ax[0].set_ylabel("sin(x)")
ax[0].set_title("sin")

ax[1].plot(x, y2)
ax[1].set_xlim(0, 10)
ax[1].set_ylim(-1, 1)
ax[1].set_xlabel("x")
ax[1].set_ylabel("cos(x)")
ax[1].set_title("cos")
```

**核心对象**：

- `fig` = 整个画布（Figure 对象）
- `ax` = 子图（Axes 对象，单个/数组）

🔥 **API 命名规则**（背一次终身受用）：

| `plt.xxx` 全局风格 | `ax.xxx` 面向对象风格 |
|---|---|
| `plt.title(...)` | `ax.set_title(...)` |
| `plt.xlabel(...)` | `ax.set_xlabel(...)` |
| `plt.ylabel(...)` | `ax.set_ylabel(...)` |
| `plt.xlim(...)` | `ax.set_xlim(...)` |
| `plt.ylim(...)` | `ax.set_ylim(...)` |
| `plt.xticks(...)` | `ax.set_xticks(...)` |
| `plt.legend(...)` | `ax.legend(...)` |

**规则**：基本都是 `plt.xxx` → `ax.set_xxx`。

### 1.3 子图布局的 3 种写法

```python
# 法 1：subplots() 一次造多个
fig, ax = plt.subplots(2, 3, figsize=(15, 8))    # 2 行 3 列
ax[0, 0].plot(x, y1)                              # 取 (0,0)
ax[1, 2].scatter(x, y2)                           # 取 (1,2)

# 法 2：单个子图也用 subplots()
fig, ax = plt.subplots(figsize=(10, 6))          # 1 个子图
ax.plot(x, y1)

# 法 3：fig.add_subplot()（视频里用过）
fig = plt.figure()
ax1 = fig.add_subplot(1, 1, 1)                   # 1 行 1 列 第 1 个
ax1.hist(df["precipitation"], bins=5)
```

### 1.4 常见图形 5 种（视频例子）

```python
# 直方图
ax.hist(df["precipitation"], bins=5)

# 散点图
ax.scatter(df["temp_max"], df["precipitation"])

# 折线图
ax.plot(x, y)

# 柱状图
ax.bar(x, y)

# 箱线图
ax.boxplot(data)
```

### 1.5 散点图的颜色 / 透明度

视频里给了个精彩例子——**按年份给散点上色**：

```python
def year_color(x):
    match x.year:
        case 2012: return "r"
        case 2013: return "g"
        case 2014: return "b"
        case 2015: return "k"

df["date"] = pd.to_datetime(df["date"])
df["color"] = df["date"].apply(year_color)

fig = plt.figure()
ax1 = fig.add_subplot(1, 1, 1)
ax1.scatter(df["temp_max"], df["precipitation"],
            c=df["color"],         # 颜色（每个点单独）
            alpha=0.5)             # 透明度（0=完全透明，1=不透明）
ax1.set_xlabel("最高气温")
ax1.set_ylabel("降水量")
```

🔥 **`alpha=0.5` 的实战价值**：散点重叠时透明度让你看出"密集程度"——不透明的话所有点重叠了你只看到最上面的点。

## 第二部分：pandas.plot（P04）—— **数据探索阶段首选**

### 2.1 一句话定位

```
pandas.plot = "DataFrame / Series 自带的 .plot 方法"
            = matplotlib 的"傻瓜版"
            = 数据探索阶段 90% 用它
```

### 2.2 7 种核心图（视频教的）

```python
import pandas as pd

# 1. 柱状图
s.plot(kind="bar")
s.plot.bar()                              # 等价语法

# 2. 折线图
s.plot(kind="line")
s.plot.line()
s.plot()                                  # 默认就是 line

# 3. 面积图
s.plot.area()

# 4. 直方图
s.plot.hist(bins=30)

# 5. 饼图
s.plot.pie()

# 6. 散点图（必须 DataFrame）
df.plot.scatter(x="a", y="b")

# 7. 蜂窝图（散点图的密度版）
df.plot.hexbin(x="a", y="b", gridsize=10)
```

### 2.3 视频实战例子

```python
# 视频 P04 第 1 个 cell：彩色柱状图
pd.cut(df["sleep_duration"], [0,5,6,7,8,9,10,11,12]) \
  .value_counts() \
  .plot(kind="bar",
        color=["red","green","blue","yellow","cyan","magenta","black","purple"])
```

**链式拆解**：

```
pd.cut(...)                ← 分箱：连续 → 8 个区间
  .value_counts()          ← 每个区间多少人
  .plot(kind="bar", ...)   ← 柱状图
```

🔥 **这就是 pandas.plot 的核心模式**——**链式从数据直接到图**，不用中间变量。

### 2.4 堆叠柱状图（**实战常用**）

视频后半段：

```python
df["sleep_quality_stage"]  = pd.cut(df["sleep_quality"], range(11))
df["sleep_duration_stage"] = pd.cut(df["sleep_duration"], [0,5,6,7,8,9,10,11,12])

df_pivot = df.pivot_table(
    values="person_id",
    index="sleep_quality_stage",
    columns="sleep_duration_stage",
    aggfunc="count",
    observed=True
)

df_pivot.plot.bar(stacked=True)          # ← 堆叠！
```

**`stacked=True`** 让多列变成"层层堆叠"，一眼看出每个 X 值里各类别的占比。

### 2.5 `kind=` vs `plot.xxx()` 等价

```python
s.plot(kind="bar")    ≡    s.plot.bar()
s.plot(kind="line")   ≡    s.plot.line()
s.plot(kind="hist")   ≡    s.plot.hist()
s.plot(kind="pie")    ≡    s.plot.pie()
df.plot(kind="scatter", x="a", y="b") ≡ df.plot.scatter(x="a", y="b")
```

**推荐用 `.plot.xxx()`**——更短、IDE 自动补全更准。

### 2.6 pandas.plot 的 6 个通用参数

```python
s.plot.bar(
    figsize=(10, 6),       # 画布大小
    title="标题",
    xlabel="x 轴标签",
    ylabel="y 轴标签",
    color="red",           # 单色或列表
    alpha=0.7,             # 透明度
    rot=45                 # x 轴标签旋转角度
)
```

## 第三部分：seaborn（P05）—— **统计图美化**

### 3.1 一句话定位

```
seaborn = "matplotlib 的统计图包"
        = 默认配色更美、统计图自带 + 分类着色超方便
```

### 3.2 安装与导入

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 中文（seaborn 共用 matplotlib 的字体设置）
plt.rcParams["font.sans-serif"] = ["KaiTi"]
```

### 3.3 视频例子：penguins 数据集

```python
penguins = pd.read_csv("penguins.csv")
penguins.dropna(inplace=True)
penguins.head()
```

数据：333 只企鹅，含 species（种类）/ bill_length_mm（喙长）/ body_mass_g（体重）等。

### 3.4 三个起手式

#### 起手式 1：`histplot`（直方图）

```python
sns.histplot(data=penguins, x="species")
# 不同种类企鹅的数量（自动按 species 分组数）

sns.histplot(data=penguins, x="bill_length_mm")
# 喙长度的分布直方图

sns.histplot(data=penguins, x="bill_length_mm", kde=True)
# 直方图 + 核密度曲线
```

🔥 **`kde=True`** = 在直方图上**叠加一条核密度曲线**——一眼看出分布形状。这是 seaborn 比 matplotlib 强的地方之一。

#### 起手式 2：`kdeplot`（纯核密度）

```python
sns.kdeplot(data=penguins, x="bill_length_mm")
```

**核密度**（KDE, Kernel Density Estimation）= "光滑版直方图"——不需要选 bins，自动给出连续的"概率密度"曲线。

#### 起手式 3：`scatterplot`（散点图）+ `hue` 分类着色（**seaborn 杀手锏**）

```python
sns.scatterplot(
    data=penguins,
    x="body_mass_g",
    y="flipper_length_mm",
    hue="sex"               # ← 按性别自动上色 + 加图例
)
```

🔥 **`hue` 是 seaborn 的招牌**——`hue=列名` 自动**按类别上色 + 自动加图例**。matplotlib 要手写循环，seaborn 一行解决。

### 3.5 seaborn 其他常用图（视频没讲但要知道）

```python
sns.boxplot(data=df, x="species", y="bill_length_mm")        # 箱线图
sns.violinplot(data=df, x="species", y="bill_length_mm")     # 小提琴图（箱线图升级版）
sns.heatmap(df.corr(), annot=True, cmap="coolwarm")          # 相关性热图（ML 必备）
sns.pairplot(df, hue="species")                              # 两两散点矩阵
sns.regplot(data=df, x="a", y="b")                           # 散点 + 回归线
```

⭐ **学完三个起手式就够 80% 场景**，其他用到再查。

### 3.6 seaborn vs matplotlib 对比

```python
# matplotlib 写法（5 行）
fig, ax = plt.subplots()
for sex in penguins["sex"].unique():
    sub = penguins[penguins["sex"] == sex]
    ax.scatter(sub["body_mass_g"], sub["flipper_length_mm"], label=sex)
ax.legend()
ax.set_xlabel("body_mass_g")
ax.set_ylabel("flipper_length_mm")

# seaborn 写法（1 行）
sns.scatterplot(data=penguins, x="body_mass_g", y="flipper_length_mm", hue="sex")
```

→ **5:1 的代码量差距**——这就是为什么数据科学家爱用 seaborn。

## 第四部分：什么时候用哪个？（**决策流程**）

```
你要画什么？
   │
   ├─ 是数据探索阶段，想"一行看一眼"
   │      → pandas.plot ✅
   │
   ├─ 是论文/正式报告，需要精细控制
   │      → matplotlib (fig/ax 风格) ✅
   │
   ├─ 是复杂统计图（热图/小提琴/分类散点）
   │      → seaborn ✅
   │
   └─ 是交互式 dashboard / 网页
          → plotly / bokeh（这两个视频没讲，未来学）
```

**实战常见组合**：

```python
# 组合 1：pandas.plot 出图 + matplotlib 微调
ax = df["price"].plot.hist(bins=30)
ax.set_title("房价分布")
ax.set_xlabel("价格")
ax.set_ylabel("频数")

# 组合 2：seaborn 出图 + matplotlib 微调
fig, ax = plt.subplots(figsize=(10,6))
sns.scatterplot(data=df, x="a", y="b", hue="cat", ax=ax)
ax.set_title("自定义标题")
```

🔥 **关键认知**：`pandas.plot` 和 `seaborn` **都返回 matplotlib 的 Axes 对象**——所以你**永远可以用 matplotlib 微调**。

## 第五部分：保存图片

```python
plt.savefig("fig.png", dpi=300, bbox_inches="tight")
```

| 参数 | 含义 |
|---|---|
| `dpi=300` | 分辨率，**300 = 印刷级别** |
| `bbox_inches="tight"` | 自动裁剪空白边 |
| `format="png"/"pdf"/"svg"` | 格式（默认根据后缀自动）|

**实战提醒**：发论文用 `pdf` 或 `svg`（矢量图），网页用 `png`。
