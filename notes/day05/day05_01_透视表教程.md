# Day05 · 第一节：透视表 pivot_table（P01）

> 视频 P01。**透视表是 Excel 数据分析的"灵魂功能"**——把一张长长的明细表 **变成多维交叉报表**。在 Pandas 里，`pivot_table` 就是它。

---

## 你已经会的部分

`groupby + unstack` 你在 [[day04_04_groupby进阶教程]] 用过：

```python
df.groupby(["a","b"])["x"].mean().unstack()
```

**这就是透视表的本质**。`pivot_table` 是它的语法糖——**更直观、更适合多列聚合**。

---

## 一句话定位

```
pivot_table = "把长表变宽表" = "groupby + unstack 的高级封装"
```

**长表 → 宽表**示意：

```
长表（明细）                            宽表（透视后）
┌────────┬────────┬────────┐           ┌────────┬─────────┬─────────┐
│ 部门    │ 性别    │ 工资    │          │         │ 男      │ 女      │
├────────┼────────┼────────┤    →     ├────────┼─────────┼─────────┤
│ 销售    │ 男     │ 12000   │          │ 销售    │ 11000   │ 13000   │
│ 销售    │ 女     │ 13000   │          │ 技术    │ 15500   │ 14000   │
│ 销售    │ 男     │ 10000   │          │ 行政    │ 8000    │ 9000    │
│ 技术    │ 男     │ 15000   │          └────────┴─────────┴─────────┘
│ ...     │        │         │                ↑           ↑
└────────┴────────┴────────┘            index 是部门   columns 是性别
                                                 单元格是工资均值
```

---

## 第一部分：4 个核心参数（**记死它**）

```python
df.pivot_table(
    values="目标列",          # 要算的数（被聚合的字段）
    index=["行维度"],          # 行方向用什么字段切
    columns=["列维度"],        # 列方向用什么字段切（可省略）
    aggfunc="mean"             # 怎么聚合（mean/sum/count/...）
)
```

| 参数 | 含义 | 类比 SQL |
|---|---|---|
| `values` | 计算什么 | `SELECT AVG(values)` |
| `index` | 行维度 | `GROUP BY index` 的主要字段 |
| `columns` | 列维度 | `GROUP BY` 后**翻成列** |
| `aggfunc` | 聚合方式 | `AVG / SUM / COUNT` 等 |

## 第二部分：视频例子拆解

### 2.1 原始数据：sleep.csv

视频用了一份睡眠数据（sleep.csv），关键列：

```
person_id  sleep_duration  stress_level  sleep_quality  occupation  gender
```

### 2.2 第 1 步：用 `cut` 做分箱（先把连续变量离散化）

```python
sleep_duration_stage = pd.cut(df["sleep_duration"], [0, 5, 6, 7, 8, 9, 10, 11, 12])
stress_level_stage   = pd.cut(df["stress_level"], 5)
```

为什么要先 cut？**透视表的行/列维度通常是"类别"**——连续数值要先切成类别才好分组。

→ 详细 cut 用法见 [[day04_04_groupby进阶教程]]。

### 2.3 第 2 步：基础透视

```python
df.pivot_table(
    values="sleep_quality",
    index=[sleep_duration_stage, stress_level_stage],
    aggfunc="mean",
    observed=True
)
```

**含义**："对每个 (睡眠时长段, 压力等级段) 组合，算睡眠质量的平均值"——结果是一张表，行有 2 层 index。

### 2.4 第 3 步：加 `columns` 维度

```python
df.pivot_table(
    values="sleep_quality",
    index=[sleep_duration_stage, stress_level_stage],
    columns=["occupation"],         # ← 把"职业"翻成列
    aggfunc="mean",
    observed=True
)
```

**结果**：

```
                                Office Worker  Manual Labor  Student  Retired
sleep_duration  stress_level
(0, 5]          (0.991, 2.8]    ...            ...           ...      ...
                (2.8, 4.6]      ...            ...           ...      ...
...
```

🔥 **这就是透视的威力**——一眼看出"每个 (时长, 压力) 组合下，不同职业的睡眠质量对比"。

### 2.5 第 4 步：`columns` 也能多列

```python
df.pivot_table(
    values="sleep_quality",
    index=[sleep_duration_stage, stress_level_stage],
    columns=["occupation", "gender"],     # ← 多层列！
    aggfunc="mean",
    observed=True
)
```

**结果**：列变成 2 层（occupation × gender 的所有组合）。

→ 这是视频里最复杂的那张大表的来源。

## 第三部分：`pivot_table` vs `groupby + unstack` 等价对照

视频里给了对比代码：

```python
# 写法 A：透视表
df.pivot_table(
    values="sleep_quality",
    index=[sleep_duration_stage, stress_level_stage],
    columns=["gender", "occupation"],
    aggfunc="mean",
    observed=True
)

# 写法 B：groupby + unstack（两次！）
df.groupby([sleep_duration_stage, stress_level_stage, "gender", "occupation"],
           observed=True)["sleep_quality"].mean().unstack().unstack()
```

**两者完全等价**——但写法 A 明显更直观。

🔥 **判别公式**：

```
df.pivot_table(
    values="X",
    index=A,
    columns=B,
    aggfunc=f
)
        ≡
df.groupby([A 列表 + B 列表])["X"].f().unstack(B 长度次)
```

**实战建议**：

- 单层 index + 不要 columns → 用 `groupby`
- 有 columns 维度 → 用 `pivot_table`（更短、更清晰）

## 第四部分：`observed` 参数（**新人爱踩**）

### 4.1 现象

```python
# observed=False（默认在某些 Pandas 版本）
df.pivot_table(values="x", index=cut_col, columns=cat_col)
# 结果可能含大量 NaN 行：所有 cut 区间 × 所有类别的组合
```

### 4.2 原因

当 `index` 或 `columns` 是 **Categorical 类型**（`pd.cut` 的结果就是），Pandas 默认会**显示所有可能组合**——即使数据里没有。

```python
# 比如 cut 切出 8 个区间，类别有 4 种
# observed=False → 8 × 4 = 32 个组合都显示，缺的填 NaN
# observed=True  → 只显示数据里出现过的组合，缺的不显示
```

### 4.3 怎么选

```python
# 90% 实战：用 True，避免输出爆炸 + 减少 NaN
df.pivot_table(..., observed=True)
```

🔥 **`observed=True` 几乎是个"应该默认开"的参数**——可惜 Pandas 历史原因默认 False。

## 第五部分：`aggfunc` 的灵活用法

### 5.1 内置字符串（最常用）

```python
df.pivot_table(values="x", index="a", aggfunc="mean")      # 均值
df.pivot_table(values="x", index="a", aggfunc="sum")       # 求和
df.pivot_table(values="x", index="a", aggfunc="count")     # 计数
df.pivot_table(values="x", index="a", aggfunc="median")
df.pivot_table(values="x", index="a", aggfunc="std")
```

### 5.2 多种聚合一起算

```python
df.pivot_table(
    values="x",
    index="a",
    aggfunc=["mean", "sum", "count"]    # ← 列表
)
```

### 5.3 不同列不同聚合

```python
df.pivot_table(
    values=["price", "sqft_living"],
    index="zipcode",
    aggfunc={"price": "mean", "sqft_living": "max"}     # ← 字典
)
```

### 5.4 自定义函数

```python
df.pivot_table(
    values="x",
    index="a",
    aggfunc=lambda s: s.max() - s.min()      # 极差
)
```

## 第六部分：实战范例（**记 5 个套路**）

### 套路 1：单字段汇总

```python
df.pivot_table(values="price", index="zipcode", aggfunc="mean")
```

→ 等价 `df.groupby("zipcode")["price"].mean()`，**不用 unstack**。

### 套路 2：交叉表

```python
df.pivot_table(values="price", index="zipcode", columns="is_renovated", aggfunc="mean")
```

→ 行 zipcode、列 is_renovated（0/1）、值是均价。

### 套路 3：多统计输出

```python
df.pivot_table(
    values="price",
    index="zipcode",
    aggfunc=["mean", "max", "min", "count"]
)
```

→ 一次出 4 列：mean / max / min / count。

### 套路 4：行汇总 / 列汇总（`margins`）

```python
df.pivot_table(
    values="price",
    index="zipcode",
    columns="is_renovated",
    aggfunc="mean",
    margins=True,                    # ← 加一行/列"总计"
    margins_name="总计"
)
```

→ 多出"总计"行和列——**Excel 透视表的"行总计/列总计"**。

### 套路 5：填空值

```python
df.pivot_table(
    values="price",
    index="zipcode",
    columns="is_renovated",
    aggfunc="mean",
    fill_value=0                      # ← NaN 填 0
)
```

## 卡点汇总（5 大坑预警）

1. **`index` 和 `columns` 都是分组键** —— 区别只是"摆在行还是列"
2. **`observed=True` 几乎要永远设** —— Categorical 类型默认显示所有组合，输出爆炸
3. **`values` 不指定时**——`pivot_table` 默认对所有数值列做聚合（可能不是你想要的）
4. **`pivot_table` 和 `pivot` 不一样** —— `pivot` 不能聚合（重复 index/columns 会报错）；`pivot_table` 能聚合（推荐）
5. **多层 `index`/`columns` 的结果是 MultiIndex** —— 取值时用 `.loc[(level1, level2), ...]`

## 速查 API 表

```python
# 基础
df.pivot_table(
    values="目标列",
    index=["行维度1", "行维度2"],
    columns=["列维度1"],
    aggfunc="mean",
    observed=True
)

# 多聚合
df.pivot_table(values="x", index="a", aggfunc=["mean", "max", "min"])

# 多列不同聚合
df.pivot_table(values=["x","y"], index="a", aggfunc={"x":"mean", "y":"sum"})

# 自定义函数
df.pivot_table(values="x", index="a", aggfunc=lambda s: s.max()-s.min())

# 加总计
df.pivot_table(..., margins=True, margins_name="总计")

# 填 NaN
df.pivot_table(..., fill_value=0)

# 等价 groupby 写法
df.groupby([index 列表 + columns 列表])["x"].mean().unstack(columns 长度次)
```
