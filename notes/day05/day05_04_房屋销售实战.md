### 2.2 IQR 异常值检测（**重点新动作**）

视频用了**统计学经典方法**——IQR（四分位距）：

```python
Q1 = data["price"].quantile(0.25)        # 下四分位（25% 分位）
Q3 = data["price"].quantile(0.75)        # 上四分位（75% 分位）

IQR = Q3 - Q1                             # 四分位距

lower_bound = Q1 - 1.5 * IQR              # 下界
upper_bound = Q3 + 1.5 * IQR              # 上界

# 只保留在 [lower, upper] 内的行
data = data[(data['price'] >= lower_bound) & (data['price'] <= upper_bound)]
```

#### 🔥 IQR 异常值检测原理

```
        ←────── Q1 ───── Median ───── Q3 ──────→
                 │                     │
                 ↓ -1.5×IQR    +1.5×IQR ↓
        ╔════════╪═══════════════════════╪════════╗
        ║        │     正常数据区          │        ║
   离群点│        │                       │   离群点 │
        ╚════════╪═══════════════════════╪════════╝
                 ↑                       ↑
              下界                       上界
```

**IQR = Q3 - Q1** 是数据"中间 50%"的宽度。
**`±1.5 × IQR`** 是统计学经验值——超出这个范围视为离群点。

**为什么是 1.5？** John Tukey（1977 年）的经验数值——对正态分布约覆盖 99% 数据。**变 3 = 极端离群点**。

#### 何时用 IQR

- **房价 / 工资 / 销售额** 这种有"极端高值"的数据
- **不要用在二分类列**（0/1 列没有"离群"）
- **不要用在有意义的极端值**（如"VIP 客户"的消费就是高得离谱，删了就没意义了）

#### 其他异常值检测方法（视频没讲）

```python
# 方法 A：3σ 准则（假设数据服从正态分布）
mean = data["price"].mean()
std = data["price"].std()
data = data[(data["price"] >= mean - 3*std) & (data["price"] <= mean + 3*std)]

# 方法 B：分位数截断（如直接砍掉 1% 和 99%）
low = data["price"].quantile(0.01)
high = data["price"].quantile(0.99)
data = data[(data["price"] >= low) & (data["price"] <= high)]

# 方法 C：Z-Score
from scipy import stats
z_scores = stats.zscore(data["price"])
data = data[abs(z_scores) < 3]
```

🔥 **实战建议**：**IQR 简单稳健**，先用它；高级场景用 `IsolationForest` / `LOF` 等机器学习方法。

## 第四步：特征工程（**真实分析师每天的工作**）

视频造了 2 个新特征：

```python
# 特征 1：房龄 = 售出年份 - 建造年份
data["age"] = data["date"].dt.year - data["yr_built"]

# 特征 2：是否翻新（0/1 二分类）
data["is_renovated"] = data["yr_renovated"].apply(lambda x: 1 if x > 0 else 0)
```

🔥 **特征工程的价值**：原始数据里 `yr_built=1979` 不直观，**`age=30` 才有意义**——和价格的关系更直接。

#### 实战常见特征工程模式

```python
# 1. 时间差（基于日期）
data["age"] = data["sale_date"].dt.year - data["build_year"]
data["days_since_renovation"] = (data["sale_date"] - data["renovation_date"]).dt.days

# 2. 二分类（基于条件）
data["is_renovated"] = data["yr_renovated"].apply(lambda x: 1 if x > 0 else 0)
# 等价向量化（更快）
data["is_renovated"] = (data["yr_renovated"] > 0).astype(int)

# 3. 比率
data["price_per_sqft"] = data["price"] / data["sqft_living"]

# 4. 分箱（连续 → 类别）
data["age_group"] = pd.cut(data["age"], bins=5)
data["price_tier"] = pd.qcut(data["price"], q=4, labels=["低","中低","中高","高"])

# 5. 编码地理位置
data["region"] = data["zipcode"].astype(str).str[:3]   # 取邮编前 3 位
```

## 第六步：相关性分析

### 6.1 看哪些列和 price 相关

```python
data[numeric_columns].corr()["price"]
# id               0.010855
# price            1.000000     ← 自己和自己 = 1
# bedrooms         0.004781
# bathrooms        0.007149
# sqft_living      0.010877
# ...
```

🔥 **解读**：

- **`> 0.3`**：弱相关
- **`> 0.5`**：中等相关
- **`> 0.7`**：强相关
- **接近 0**：基本无关
- **负数**：反向相关

视频里所有相关系数都接近 0——**这是合成数据集**，特征之间无真实因果关系。**真实数据集里 `sqft_living` 和 `price` 通常 > 0.7**。

### 6.2 全相关矩阵 + 热图

```python
import seaborn as sns
import matplotlib.pyplot as plt

corr = data[numeric_columns].corr()

plt.figure(figsize=(12, 10))
sns.heatmap(corr, annot=True, cmap="coolwarm", center=0, fmt=".2f")
plt.title("特征相关性热图")
plt.show()
```

| 参数 | 含义 |
|---|---|
| `annot=True` | 每格显示数字 |
| `cmap="coolwarm"` | 蓝（负） → 红（正） |
| `center=0` | 让 0 是白色 |
| `fmt=".2f"` | 保留 2 位小数 |

🔥 **热图是 ML 特征选择的入口**——先看哪些特征和目标变量相关，再决定保留哪些。

## 第七步：分组 / 透视分析（**全部 day04+day05 知识点应用**）

### 7.1 按地区看均价

```python
# 方式 A：groupby
data.groupby("zipcode")[["price","sqft_living","bedrooms"]].mean()

# 方式 B：agg 同时多统计
data.groupby("zipcode").agg({
    "price": "mean",
    "sqft_living": "mean",
    "bedrooms": "mean"
})

# 方式 C：pivot_table（视频用了这个）
data.pivot_table(values=["price","sqft_living","bedrooms"],
                 index="zipcode",

```

→ **3 种写法等价**——选哪种看你顺手。

## 完整脚本（**整合**）

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from matplotlib import rcParams
rcParams["font.sans-serif"] = ["SimHei"]

# 1. 读入
data = pd.read_csv("house_sales.csv", parse_dates=["date"])

# 2. 清洗
data.dropna(inplace=True)
Q1, Q3 = data["price"].quantile([0.25, 0.75])
IQR = Q3 - Q1
data = data[(data["price"] >= Q1 - 1.5*IQR) & (data["price"] <= Q3 + 1.5*IQR)]

# 3. 特征工程
data["age"] = data["date"].dt.year - data["yr_built"]
data["is_renovated"] = (data["yr_renovated"] > 0).astype(int)
data["age_group"] = pd.cut(data["age"], 5)

# 4. 描述统计
numeric_cols = data.select_dtypes(include=[np.number]).columns
print(data[numeric_cols].describe())

# 5. 相关性
print(data[numeric_cols].corr()["price"].sort_values(ascending=False))

# 6. 分组分析
print(data.pivot_table(values="price",
                        index=data["date"].dt.year,
                        columns="is_renovated",
                        aggfunc="mean").head())

# 7. 可视化（2×2 子图）
fig, ax = plt.subplots(2, 2, figsize=(15, 10))

# 7.1 房价分布
ax[0,0].hist(data["price"], bins=30, edgecolor='k')
ax[0,0].set_title("房价分布")

# 7.2 卧室 vs 房价
ax[0,1].scatter(data["bedrooms"], data["price"], alpha=0.3)
ax[0,1].set_title("卧室数量 vs 房价")
ax[0,1].set_xlabel("卧室数")
ax[0,1].set_ylabel("房价")

# 7.3 年度趋势
data.set_index("date")["price"].resample("YE").mean().plot(ax=ax[1,0])
ax[1,0].set_title("年度均价")

# 7.4 房龄分组箱线图
sns.boxplot(data=data, x="age_group", y="price", ax=ax[1,1])
ax[1,1].set_title("不同房龄段房价分布")
ax[1,1].tick_params(axis='x', rotation=45)

plt.tight_layout()
plt.savefig("house_analysis.png", dpi=300, bbox_inches="tight")
plt.show()
```

→ **这就是数据分析师的真实代码**——50 行能产出一份完整分析报告。

## 卡点汇总（4 大坑预警）

1. **IQR 异常值的 `1.5 × IQR`** —— 不是拍脑袋，是 Tukey 1977 年的经验
2. **`select_dtypes(include=[np.number])`** —— `describe` / `corr` 前永远先选数值列
3. **`is_renovated = (s > 0).astype(int)`** vs `.apply(lambda)` —— 向量化快 100 倍
4. **`pivot_table` 多列聚合时用 `values=[...]`** —— 比 `.agg({...})` 更直观
