## ① P01：透视表 `pivot_table`（**重头戏 1**）

### 一句话定位

```
透视表 = "Excel 的'数据透视表' = groupby + unstack 的高级封装"
```

**视频经典例子**：

```python
df.pivot_table(
    values="sleep_quality",                              # 要统计什么
    index=[sleep_duration_stage, stress_level_stage],    # 行维度
    columns=["occupation", "gender"],                    # 列维度（可多列）
    aggfunc="mean",                                       # 怎么聚合
    observed=True                                         # 不显示空组合
)
```

输出：一张 **多维交叉表**，行/列各有多层标签。

🔥 **`pivot_table` vs `groupby + unstack` 完全等价**——前者是后者的语法糖：

```python
# 两种写法等价
df.pivot_table(values="x", index="a", columns="b", aggfunc="mean")
df.groupby(["a","b"])["x"].mean().unstack()
```

→ 详细见 [[day05_01_透视表教程]]。

## ② P02：日期处理进阶（**day03 已学基础**）

### 你已经会的（day03 P04）

```python
pd.to_datetime(s)
s.dt.year / month / day / quarter
s.dt.to_period("M")
```

### 这一节新增 🆕

```python
# 1. Python 标准库 datetime
from datetime import datetime
date = datetime(2025, 1, 1)
date.year / month / day / weekday() / strftime("%A")
date2 - date1                          # → timedelta

# 2. 混合日期格式自动识别
pd.to_datetime(["4th of July, 2015", "2015-Jul-6", "20150708"], format="mixed")

# 3. read_csv 时直接转日期
df = pd.read_csv(..., parse_dates=["date"])

# 4. pd.Timestamp（单个日期对象）
d = pd.Timestamp("2015-01-01 09:08:07.123456")
d.year / month / hour / minute / second / microsecond

# 5. timedelta 差值能当 index
df["diff"] = df["ymd"] - df["ymd"][0]      # TimedeltaIndex
df.set_index("diff", inplace=True)

# 6. date_range 生成日期序列
pd.date_range(start="2015-07-03", end="2015-07-10")
pd.date_range("2015-07-03", periods=5, freq="h")
pd.date_range("2015-07-03", periods=10, freq="QE-JAN")

# 7. resample 时间重采样（**最重要**）
df.set_index("date", inplace=True)
df.resample("ME").mean()                  # 月末重采样：日 → 月
df.resample("YE").mean()                  # 年末
df.resample("h").sum()                    # 时
```

🔥 **`resample` 是这一节最重要的新东西**——把日数据按月/年/季汇总，**比 groupby+to_period 更直接**。

→ 详细见 [[day05_02_日期处理进阶教程]]。

## ③ P03+P04+P05：可视化三件套（**重头戏 2**）

### 层次关系（**先理解这个，再学 API**）

```
            ┌─────────────────────┐
            │   底层：matplotlib  │  ← Python 可视化的"汇编语言"
            │   plt + fig/ax     │     灵活但繁琐
            └──────────┬──────────┘
                       │
        ┌──────────────┴──────────────┐
        ↓                              ↓
  ┌──────────────┐              ┌──────────────┐
  │ pandas.plot  │              │   seaborn    │
  │ s.plot.bar() │              │ sns.histplot │
  │ 数据直接出图 │              │ 统计图美观   │
  └──────────────┘              └──────────────┘
        ↑                              ↑
  你已用过                        全新内容
  (P05_Weather)
```

**3 种工具的定位**：

| 工具 | 一句话 | 何时用 |
|---|---|---|
| **matplotlib** | "终极灵活，全部细节可控" | 精细微调、出版论文图 |
| **pandas.plot** | "DataFrame 一行出图" | **数据探索阶段 90% 场景** |
| **seaborn** | "统计图自动美化" | 复杂统计图（小提琴、热图、回归）|

### P03 — matplotlib 两种风格

```python
# 风格 A：plt 全局接口（脚本风格）
plt.figure(figsize=(10,6))
plt.subplot(2, 1, 1)
plt.plot(x, y1)
plt.xlabel('x'); plt.ylabel('sin(x)'); plt.title('sin')

# 风格 B：fig/ax 面向对象（推荐）
fig, ax = plt.subplots(2, figsize=(10,6))
ax[0].plot(x, y1)
ax[0].set_xlabel('x')
ax[0].set_title('sin')
```

🔥 **永远用风格 B**——可控、可命名、能保存。风格 A 是给 MATLAB 转过来的人用的。

### P04 — pandas.plot 7 种图

```python
s.value_counts().plot(kind="bar")           # 柱状图
s.plot(kind="line") / plot.line()           # 折线图
s.plot.area()                                # 面积图
s.plot.hist()                                # 直方图
s.plot.pie()                                 # 饼图
df.plot.scatter(x="a", y="b")                # 散点图
df.plot.hexbin(x="a", y="b", gridsize=10)    # 蜂窝图（散点密度版）
df.plot.bar(stacked=True)                    # 堆叠柱状图
```

🔥 **`.plot(kind="bar")` ≡ `.plot.bar()`**——两种写法等价，后者更短。

### P05 — seaborn 3 个起手式

```python
sns.histplot(data=df, x="col")                       # 直方图
sns.histplot(data=df, x="col", kde=True)             # 直方图+核密度
sns.kdeplot(data=df, x="col")                        # 纯核密度
sns.scatterplot(data=df, x="a", y="b", hue="cat")    # 散点（按类别上色）
```

🔥 **seaborn 的杀手锏**：`hue=` 参数——按某列**自动分类着色**，比 matplotlib 手动配色快 10 倍。

→ 三个合并讲，详细见 [[day05_03_可视化教程]]。

## 你看 day05 会撞到的"卡点"预测

1. **透视表的 `index` 和 `columns` 区别** —— 行/列维度都能放多个字段，多层 index
2. **`observed=True/False` 的影响** —— 用 `pd.cut` 做 index 时，没出现的组合显不显示
3. **matplotlib 两种风格混用** —— 教程一会儿 `plt.xxx` 一会儿 `ax.xxx`，第一次看会懵
4. **中文不显示**（默认 matplotlib 字体不支持中文）—— 加 `rcParams["font.sans-serif"] = ["SimHei"]`
5. **`resample("ME") vs "M"`** —— Pandas 2.x 改了 freq 字符串，`M` 已弃用要用 `ME`
6. **`plt.show()` 在 Jupyter 不需要**，但脚本里需要

撞到任何一个**直接告诉我**。
