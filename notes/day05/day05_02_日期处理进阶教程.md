## 第一部分：Python 标准库 `datetime`

### 1.1 视频例子

```python
from datetime import datetime

date1 = datetime(year=2000, month=1, day=1)
date2 = datetime.now()

print(date1)              # 2000-01-01 00:00:00
print(date1.year)         # 2000
print(date1.month)        # 1
print(date1.day)          # 1
print(date2.weekday())    # 0=Monday ... 6=Sunday
print(date2.strftime("%A"))   # "Monday"
print(date2 - date1)      # 9368 days, 10:27:46
```

### 1.2 `datetime` 是 Python 自带的（不是 Pandas）

```
Python 标准库:   datetime.datetime / datetime.timedelta
                       ↓ 升级
Pandas 自己的:   pd.Timestamp / pd.Timedelta（**完全兼容**，但更强）
```

**实战推荐**：除非写不依赖 Pandas 的代码，否则**直接用 `pd.Timestamp`**——功能更强、和 Series/DataFrame 兼容更好。

### 1.3 `strftime` 格式符（**记常用 5 个**）

```python
date2.strftime("%Y-%m-%d")             # "2025-08-25"
date2.strftime("%Y-%m-%d %H:%M:%S")    # "2025-08-25 10:27:46"
date2.strftime("%A")                    # "Monday"（完整周几）
date2.strftime("%a")                    # "Mon"（简写）
date2.strftime("%B")                    # "August"
```

| 格式符 | 含义 | 例 |
|---|---|---|
| `%Y` | 4 位年 | 2025 |
| `%y` | 2 位年 | 25 |
| `%m` | 月（01-12）| 08 |
| `%d` | 日 | 25 |
| `%H` | 时（24h）| 10 |
| `%M` | 分 | 27 |
| `%S` | 秒 | 46 |
| `%A` | 完整周几名 | Monday |
| `%a` | 缩写周几 | Mon |
| `%B` | 完整月份名 | August |

## 第二部分：混合日期格式 `format="mixed"`

视频例子：

```python
pd.to_datetime(
    ["4th of July, 2015", "2015-Jul-6", "07-07-2015", "20150708"],
    format="mixed"
)
# DatetimeIndex(['2015-07-04', '2015-07-06', '2015-07-07', '2015-07-08'])
```

**含义**：**一列里日期格式不统一**——Pandas 也能自动识别每个。

🔥 **`format="mixed"` 是 Pandas 2.x 新增**——之前是 `infer_datetime_format=True`（已弃用）。

**使用场景**：

- 业务数据有 `"2025-01-06"` 和 `"06/01/2025"` 混着的
- 历史数据库迁移导致格式不统一

**注意**：`format="mixed"` **比指定 `format=` 慢得多**——大文件请提前清洗格式统一。

## 第三部分：`read_csv` 时直接转日期（**实战必备**）

### 3.1 视频例子

```python
df = pd.read_csv("weather.csv", parse_dates=["date"])
df.info()
# date列已经是 datetime64[ns]，不用再 to_datetime
```

### 3.2 `parse_dates` 的 3 种写法

```python
# 单列
pd.read_csv("...", parse_dates=["date"])

# 多列各自转
pd.read_csv("...", parse_dates=["start_date", "end_date"])

# 多列拼成一个日期（旧版本支持）
pd.read_csv("...", parse_dates={"datetime": ["year", "month", "day"]})
```

🔥 **始终用 `parse_dates`**：

- ✅ 一行解决（不用再 `df["x"] = pd.to_datetime(...)`）
- ✅ 大文件**省时间**（read_csv 内部用 C 加速）
- ✅ 出错时立刻报错，不会等到后续 `.dt` 调用才发现

## 第四部分：`pd.Timestamp` —— 单个日期对象

### 4.1 视频例子

```python
d = pd.Timestamp("2015-01-01 09:08:07.123456")

d.year          # 2015
d.month         # 1
d.day           # 1
d.hour          # 9
d.minute        # 8
d.second        # 7
d.microsecond   # 123456
```

### 4.2 `Timestamp` vs `datetime` vs Series.dt

| 用法 | 对象 | 属性写法 |
|---|---|---|
| Python `datetime` | 单个日期 | `d.year`（无 `.dt`） |
| `pd.Timestamp` | 单个日期 | `d.year`（无 `.dt`） |
| Series of dates | 日期列 | `s.dt.year`（**必须 `.dt`**） |

🔥 **关键认知**：

- **单个 Timestamp**：直接 `.year / .month / .day`
- **整列 Series**：必须 `.dt.year / .dt.month / .dt.day`

```python
df["date"][0].year           # ✅ 单个元素，无 .dt
df["date"].dt.year           # ✅ 整列，必须 .dt
df["date"].year              # ❌ AttributeError
```

→ 这点 day03 笔记里也强调过，**容易出错**。

## 第五部分：日期序列 `pd.date_range`

### 5.1 视频例子

```python
pd.date_range(start="2015-07-03", end="2015-07-10")
# DatetimeIndex(['2015-07-03', '2015-07-04', ..., '2015-07-10'])

pd.date_range("2015-07-03", periods=5)
# 5 天

pd.date_range("2015-07-03", periods=5, freq="h")
# 5 个小时

pd.date_range("2015-07-03", periods=10, freq="QE-JAN")
# 10 个季度（1 月作为财年开始）
```

### 5.2 `freq` 参数（**核心**）

视频里用了 `QE-JAN`——这是 Pandas 2.x 新的 freq 字符串体系。

```
旧版（Pandas 1.x）     →     新版（Pandas 2.x）
─────────────────────────────────────────────
"D"  天                      "D"   天（不变）
"H"  时                      "h"   时（变小写）
"M"  月末                    "ME"  月末（Month End）
"MS" 月初                    "MS"  月初（不变）
"Q"  季度末                  "QE"  季度末（Quarter End）
"Y"/"A" 年末                 "YE"  年末（Year End）
"W"  周                      "W"   周（不变）
"B"  工作日                  "B"   工作日（不变）
```

🔥 **Pandas 2.x 升级提醒**：

- 用 **大写 + E** 表示"末"（`ME` / `QE` / `YE`）
- 用 **大写 + S** 表示"初"（`MS` / `QS` / `YS`）
- **`M` 已弃用**——用 `ME` 替代

```python
# 旧（会有 DeprecationWarning）
pd.date_range("2025-01-01", periods=12, freq="M")

# 新（推荐）
pd.date_range("2025-01-01", periods=12, freq="ME")
```

### 5.3 `freq` 的"复合"用法

```python
pd.date_range("2025-01-01", periods=5, freq="2h")        # 每 2 小时
pd.date_range("2025-01-01", periods=5, freq="15min")     # 每 15 分钟
pd.date_range("2025-01-01", periods=5, freq="3D")        # 每 3 天
```

### 5.4 实战用途

```python
# 1. 造测试数据
ts = pd.Series(np.random.rand(100),
               index=pd.date_range("2025-01-01", periods=100))

# 2. 补齐日期（缺失的日期补 NaN）
all_dates = pd.date_range(start=df["date"].min(), end=df["date"].max())
df = df.set_index("date").reindex(all_dates)

# 3. ML 时间序列预测的"未来日期 x 轴"
future_dates = pd.date_range(start="2025-01-01", periods=30, freq="D")
```

## 第六部分：`resample` 时间重采样（**Day05 最重要的新东西**）

### 6.1 一句话定位

```
resample = "按时间重新分桶 + 聚合"
         = groupby + 时间桶 的专用语法
```

**经典场景**：

- **降采样（downsampling）**：日数据 → 月数据 / 月数据 → 年数据
- **升采样（upsampling）**：日数据 → 小时数据（需要插值）

### 6.2 视频例子

```python
df = pd.read_csv("weather.csv")
df["date"] = pd.to_datetime(df["date"])
df.set_index("date", inplace=True)        # ← 必须把日期设为 index！

# 月末重采样
df[["temp_max", "temp_min"]].resample("ME").mean()
# 输出：每个月一行（48 行 = 4 年 × 12 月）

# 年末
df[["temp_max", "temp_min"]].resample("YE").mean()
# 输出：4 行（2012/2013/2014/2015）
```

🔥 **`resample` 的强制前提**：**index 必须是 DatetimeIndex**。

```python
# 错的
df.resample("ME")               # ❌ index 不是日期，报错

# 对的（两种方式）
df.set_index("date").resample("ME")              # 把 date 设为 index
df.resample("ME", on="date")                     # 或者指定 on=
```

### 6.3 `resample` vs `groupby + to_period`

```python
# 方式 A：resample
df.set_index("date").resample("ME").mean()

# 方式 B：groupby + to_period
df.groupby(df["date"].dt.to_period("M")).mean()
```

**两者结果几乎等价**，但：

| 方式 | 优势 |
|---|---|
| `resample` | 语法**更简洁**、内置时间补齐、支持升采样 |
| `groupby + to_period` | 不要求 index 是日期、灵活 |

**实战推荐**：**纯时间序列分析永远用 `resample`**——它就是为这种场景设计的。

### 6.4 `resample` 的 5 个常见姿势

```python
# 1. 降采样 + 均值
df.resample("ME").mean()                # 月均值
df.resample("YE").sum()                 # 年总和
df.resample("W").max()                  # 每周最大

# 2. 多种聚合
df.resample("ME").agg(["mean", "max", "min"])
df.resample("ME").agg({"temp_max": "mean", "wind": "max"})

# 3. 升采样 + 前向填充
df.resample("h").ffill()                # 日数据扩展成小时，缺的用前一个填

# 4. 自定义函数
df.resample("ME").apply(lambda g: g.max() - g.min())

# 5. 配合 plot 出图
df["temp_max"].resample("ME").mean().plot()
```

### 6.5 真实例子：算"每月最高气温"

```python
df = pd.read_csv("weather.csv", parse_dates=["date"]).set_index("date")

# 方式 A：resample
monthly_high = df["temp_max"].resample("ME").max()

# 方式 B：groupby + to_period（你之前写过）
monthly_high = df.groupby(df.index.to_period("M"))["temp_max"].max()

# 两者结果一样，但 A 更简洁
```

## 第七部分：日期差值 `timedelta`

### 7.1 视频例子

```python
df["dif"] = df_date - df_date[0]      # 每一行减去第 0 行的日期
df.info()
# dif    timedelta64[ns]                ← 这是新类型
```

### 7.2 `Timedelta` 是什么

```python
td = pd.Timestamp("2025-01-10") - pd.Timestamp("2025-01-01")
type(td)        # pandas.Timedelta
td.days         # 9
td.total_seconds()   # 777600
```

### 7.3 把 Timedelta 当 index

视频里展示了把"日期差"做 index：

```python
df["diff"] = df["ymd"] - df["ymd"][0]
df.set_index("diff", inplace=True)
# 现在 df.index 是 TimedeltaIndex（0 days, 1 days, 2 days, ...）
```

**用途**：

- 实验"第 0 天、第 1 天、第 2 天..."的时间序列
- 不关心绝对日期，只关心"经过多久"

## 卡点汇总（5 大坑预警）

1. **`s.dt.year` vs `ts.year`** —— Series 必须 `.dt`，单个 Timestamp 不要 `.dt`
2. **`resample` 前必须把日期设为 index** —— 否则报错
3. **Pandas 2.x `freq` 改了** —— `M → ME`、`Y → YE`、`Q → QE`、`H → h`
4. **`format="mixed"` 慢** —— 大数据请提前清洗格式
5. **`parse_dates` 是 `read_csv` 的参数，不是单独函数** —— 一行解决日期转换
