🧱 Phase 1 · 基础地基(预计 2-3 周)

目标:把 Python 生态和 ML/DL 必备概念过一遍,为后面打底

阶段 01 · Python 大模型人工智能语言

🟢 速通3-5 天
重点
基础语法 / 装饰器 / async / 生成器 / 类型注解 —— 仅"能读懂"
掌握程度
遇到 AI 写的代码能看懂在干嘛即可,不要求会徒手写
📌 你已经决定的策略:不专门看课,后面遇到不懂的特性直接问 AI,30 秒解决。你 11 年的工程素养完全 hold 得住这种"用到再学"模式。
🎯 为什么这么做:语法不是壁垒,是工具。你卡点不会在语法,会在 AI 概念。把时间留给值得的地方。

阶段 02 · 算法与数据结构

🟢 速通3-5 天
重点
面试高频题:数组 / 链表 / 树 / DP / 双指针 / 滑动窗口
掌握程度
LeetCode 中等题能 20 分钟内写出来
🎯 为什么:AI 应用岗的算法面比纯算法岗轻,但仍会考。你 iOS 写过的算法基础够用,刷题就是恢复手感。

阶段 03 · MySQL + Linux/Shell

🟢 速通2-3 天
重点
SQL 基础查询 + Linux 常用命令
掌握程度
能写 JOIN / GROUP BY,会用 ssh/scp/grep/awk
🎯 为什么:iOS 工作中接触过,扫一眼复习生疏的部分即可,别花大块时间。

阶段 04 · 数据分析(Numpy / Pandas)

🟡 理解5-7 天
重点
  • Numpy 数组操作 / 广播机制(后面所有 tensor 操作的基础)
  • Pandas DataFrame 增删改查 / groupby / merge
掌握程度
看到代码能读懂,要写时能查文档实现
🎯 为什么:后面 ML/DL/数据预处理高频使用。不需要熟练手写,但要"看到 df.groupby(...).agg(...) 不头晕"。

🧠 Phase 2 · ML/DL 概念地基(预计 3-4 周)

目标:为 Transformer 和后续大模型内容铺路,这一段会有几个真硬骨头

阶段 05 · 机器学习

🟡 理解1-2 周
重点
  • 线性 / 逻辑回归 · 决策树 · 随机森林 · XGBoost
  • SVM · KMeans · PCA(知道概念即可)
  • 过拟合 / 正则化 / 评估指标(必考)
掌握程度
能用 sklearn 三行调出来 + 面试能讲 2 分钟原理
📌 明确跳过:手推梯度下降、SVM 核函数数学推导、从零实现决策树。这些是算法岗的事,不是你的。
🎯 为什么:大模型应用岗的"面试装备",不是"工作装备"。理解概念应付面试即可。

阶段 06 · 深度学习 ⚠️ 分两半

🔴 核心2-3 周(后半占大头)
前半(3-5 天 · 🟡 理解)
  • 神经网络基础 / 反向传播(概念)
  • CNN / RNN / LSTM —— 知道是干嘛、什么场景用
  • 激活函数 / 损失函数 / 优化器
后半(1-2 周 · 🔴 死磕)
  • Self-Attention 机制(为什么除以 √d_k?)
  • Multi-Head Attention(每个头学什么?)
  • 位置编码(Sinusoidal / RoPE / ALiBi)
  • Encoder vs Decoder vs Decoder-only
  • KV Cache(推理加速核心)
🎯 为什么硬核:整个大模型时代建在 Transformer 上。这块没吃透,后面阶段 08/10/13 全部内容都"浮在上面"。强制动作:白纸画出完整架构图,标出每一步张量维度,自己讲一遍——讲不顺的地方就是没懂。

阶段 07 · 项目一

⚪ 跳过--
🎯 为什么跳:这是早期阶段的入门项目,放简历上没有差异化优势。把时间留给后面阶段 11、17/18/19 的项目。

🚀 Phase 3 · 大模型核心战场(预计 6-8 周)

目标:这是你简历的主战场,**投入最多精力的部分在这里**

阶段 08 · NLP 与模型训练

🟠 重点1-2 周
重点
  • Tokenizer(BPE / WordPiece / SentencePiece)
  • 预训练 / SFT / RLHF 流程概念
  • HuggingFace transformers 库的使用
  • 数据集构造与 DataLoader
掌握程度
能说清楚"一个模型从数据到上线的完整链路"
🎯 为什么:面试官超爱问"训练流程",答得有结构 = 加分。也是阶段 13 微调的前置。

阶段 09 · 项目二(NLP 智品发布)

⚪ 速看--
🎯 为什么:有更亮的项目可选(阶段 11、17-19)。这个扫一下知道做了什么就行。

阶段 10 · Agent / LangChain / MCP ⭐ 主战场

🔴 核心2-3 周
重点
  • LangChain 核心组件:Chains / Tools / Memory / Output Parser
  • Agent 架构:ReAct / Function Calling / Tool Use
  • Prompt 工程的工程化实践
  • MCP(Model Context Protocol)的服务端/客户端实现
  • 流式输出 / 异步调用 / 错误恢复
掌握程度
独立从 0 搭一个能调用多个工具的 Agent,接外部 API,完成多轮对话
🎯 为什么是主战场:"AI 应用开发岗"的招聘 JD 70% 都在问这一块。你的简历项目主标签会是这里。

阶段 11 · 知识图谱 Neo4j(项目候选 ①)

🟠 重点1-2 周
重点
  • Cypher 查询语言基础
  • 实体抽取 + 关系抽取(LLM 辅助)
  • GraphRAG 思想
掌握程度
能完整跑通"文本 → 实体关系 → 入图 → 问答"
🎯 为什么:知识图谱 + LLM 是企业落地的高频组合。完整做完一遍,简历上能写"GraphRAG 实战"——加分。

阶段 12 · Coze + Dify

🟡 理解3-5 天
重点
两个平台的工作流编排方式 / 插件机制
掌握程度
能搭一个简单 bot,知道平台局限性
🎯 为什么不深入:低代码平台是"产品视角",不是"工程视角"。了解 + 演示即可。简历可写"熟悉 Coze/Dify 工作流编排"。

阶段 13 · LoRA 微调实战 ⭐ 硬门槛

🔴 核心2-3 周
重点
  • SFT 全量微调 vs LoRA / QLoRA 的差异与选型
  • peft 库 + trl + transformers 全栈使用
  • DeepSpeed / Unsloth 加速训练
  • 数据集构造与质量控制
  • 评估指标 + 推理部署
掌握程度
能独立用 LoRA 微调 Qwen/Llama 类模型,完整走完训练→评估→推理
🎯 为什么硬门槛:"做过微调"是简历从"会调 API"跨到"懂模型"的关键分水岭。面试给薪资是看这个的。

阶段 14 · 智能体强化学习

🟡 理解5-7 天
重点
RLHF / PPO / DPO 的思想 + 应用场景
掌握程度
面试能讲清楚"为什么需要 RLHF",知道 DPO 是 RLHF 的简化替代
🎯 为什么不深入:除非你目标是算法岗,否则 RL 实操在应用岗几乎用不到。但概念面试会问。

阶段 15 · 多模态大模型

🟡 理解5-7 天
重点
CLIP / BLIP / LLaVA 架构思路 · 视觉 token 化
掌握程度
知道 VLM 怎么把图变成 token 喂给 LLM 即可
🎯 为什么:多模态正在变热,但当前主流岗位还是文本为主。了解概念,有时间可以做个小 demo。

阶段 16 · LangGraph ⭐ 高级编排

🔴 核心1-2 周
重点
  • 状态机思想下的 Agent 编排
  • 多智能体协作 / 条件路由 / 循环控制
  • 持久化 + checkpointing
掌握程度
能用 LangGraph 实现复杂业务流(对比简单 LangChain Agent 的优势能说清)
🎯 为什么:2026 年最新的 Agent 编排方案,简历上写"用 LangGraph 实现多智能体"比"用 LangChain Agent"高一档。

目标:把学过的串起来,产出 2-3 个能讲透的项目 + 复盘面经

阶段 17/18/19 · Agent 项目(挑 1 个)

🟠 重点1-2 周
三选一
  • 阶段 17 · 点餐 Agent —— 业务场景清晰,容易讲
  • 阶段 18 · 多智能体 ITS —— 技术含量最高,推荐 ⭐
  • 阶段 19 · 智能体问数 —— Text2SQL 类,需求方向热门

附送 01 · RAG 与项目实战 ⭐

🔴 核心1-2 周
重点
  • 文档切分策略 / Embedding 模型选型
  • 向量库(Chroma / Milvus / Faiss)选型
  • Rerank 机制 · 混合检索
  • GraphRAG / HyDE / Self-RAG 等进阶
掌握程度
能搭企业级 RAG,讲清每个组件的选型理由
🎯 为什么必学:"RAG"几乎是 2026 年 AI 应用岗的标配技能,面试必问。强烈建议这是你简历上的第二个核心项目。

🧭 五条不要忘的原则

  1. "看完 ≠ 学会",项目大于看课。简历上能 demo 的 2 个项目,远比看完所有视频更值钱。
  2. Transformer 是分水岭。这一关跨过去,后面一马平川;跨不过去,后面所有内容都浮着。值得花 2 周。
  3. 不要陷入"补基础"陷阱。遇到不会的概念问 AI,不要回过头啃整本《深度学习》。前进的速度比知识的完整性更重要。
  4. iOS 11 年是优势不是包袱。讲项目的时候多带工程视角(架构 / 可靠性 / 扩展性),这是应届生讲不出来的差异化。
  5. 青岛市场 + 远程机会一起看。青岛本地 AI 岗位密度有限,远程岗位(北京/上海/杭州团队招远程)能极大扩大选择面。
