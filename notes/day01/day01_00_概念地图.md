## 一句话定位 ndarray

> **ndarray = NumPy 的"多维数组"**——可以是 1D（向量）、2D（矩阵）、3D 甚至 N 维。**底层是连续内存 + C 实现**，所以批量计算比 Python list **快百倍**。

```
1D ndarray  ──  [1, 2, 3, 4, 5]                   向量 (shape: (5,))
2D ndarray  ──  [[1,2,3],                          矩阵 (shape: (2,3))
                  [4,5,6]]
3D ndarray  ──  [[[..],[..]], [[..],[..]]]         张量 (shape: (2,2,3))
```

**iOS 老兵的对应**：

```swift
// Swift 没有真正的多维数组类型，只能：
let arr: [[Double]] = [[1,2,3], [4,5,6]]   // 嵌套数组 → 性能差
let matrix = vDSP_...                       // Accelerate 框架 → 不通用

// NumPy 的 ndarray 把"高性能多维数组"做成了一等公民
```

## ① P02：ndarray 的 5 个属性

视频里就这 **5 个属性**——一口气过完：

```python
arr = np.array([[1,2,3], [4,5,6]])

arr.ndim       # 2          ← 维度数（几 D）
arr.shape      # (2, 3)     ← 各维度大小（2 行 3 列）
arr.size       # 6          ← 元素总数 = 2 × 3
arr.dtype      # int64      ← 元素类型
arr.itemsize   # 8          ← 每个元素几字节（int64 = 8 字节）
```

🔥 **关键认知**：

- `shape` 是**元组**：`(2, 3)` 不是 `[2, 3]`，1D 数组的 shape 是 `(5,)` 不是 `(5)`（注意逗号）
- `size = shape 各维度乘积`：`(2,3,4).size = 24`
- `dtype` 决定每个元素占多少字节：`int64=8`、`float32=4`、`bool=1`

→ 详细见 [[day01_01_ndarray教程]]，**5 分钟扫完**就行。

## ② P03：ndarray 的 9 类创建方式（**Day01 重头戏**）

视频里给了很多 API，分类后是 **9 大类**：

```
1. 从 Python 列表造        →  np.array / np.asarray
2. 全 0 / 全 1            →  np.zeros / np.ones
3. 未初始化（最快）        →  np.empty
4. 填指定值               →  np.full
5. 仿 shape 造空表        →  np.zeros_like / ones_like / full_like
6. 等差序列               →  np.arange / np.linspace
7. 等比序列               →  np.logspace
8. 随机数据               →  np.random.rand / randint / uniform / randn
9. 矩阵（特殊）           →  np.matrix
```

| 方法 | 一句话 | 实战频率 |
|---|---|---|
| `np.array([1,2,3])` | 从列表造 | ⭐⭐⭐ 天天用 |
| `np.zeros((2,3))` | 全 0 占位 | ⭐⭐⭐ 算法初始化必备 |
| `np.ones((2,3))` | 全 1 | ⭐⭐ |
| `np.full((2,3), 6)` | 全 6 | ⭐ |
| `np.empty((2,3))` | 未初始化（**最快**）| ⭐ 性能敏感场景 |
| `np.arange(0, 10, 2)` | `[0,2,4,6,8]`，类似 range | ⭐⭐⭐ |
| `np.linspace(0, 1, 5)` | **5 个等分点**：`[0, .25, .5, .75, 1]` | ⭐⭐⭐ 画图时 x 轴必备 |
| `np.logspace(2, 5, 4, base=2)` | 等比数列：`[4, 8, 16, 32]` | ⭐ 学习率调度时用 |
| `np.random.rand(2,3)` | `[0,1)` 均匀分布 | ⭐⭐⭐ 造测试数据 |
| `np.random.randint(0, 5, (2,3))` | 整数 | ⭐⭐⭐ |
| `np.random.randn(2,3)` | 标准正态（**ML 初始化必备**）| ⭐⭐⭐ |

→ 详细见 [[day01_01_ndarray教程]]。

### 这一节最容易混的 3 个

1. **`array` vs `asarray`** —— 入参是 list 时无差；入参已是 ndarray 时 `array` 拷贝、`asarray` 不拷贝
2. **`linspace` vs `arange`** —— `linspace(0,10,5)` 是"切 5 个点"；`arange(0,10,2)` 是"步长 2"
3. **`rand` vs `randn`** —— `rand` 是 `[0,1)` 均匀；`randn` 是标准正态（含负数）

## ③ P04：数据类型（dtype）

### 9 个常用 dtype

```python
# 整数
np.int8 / int16 / int32 / int64      # 1/2/4/8 字节
np.uint8 / uint16 / uint32 / uint64  # 无符号整数

# 浮点
np.float16 / float32 / float64       # 2/4/8 字节

# 其他
np.bool_       # 1 字节
np.complex64 / complex128  # 复数
```

### 两种指定方式

```python
# 方式 A：传 dtype 类对象
arr = np.array([1,2,3], dtype=np.int64)
arr = np.zeros((2,3), dtype=np.float32)

# 方式 B：传字符串简写（**视频里教的**）
arr = np.array([1,2,3], dtype="i8")     # i8 = int64
arr = np.zeros((2,3), dtype="f4")       # f4 = float32
```

**字符串简写对照表**：

| 字符串 | 等价 | 字节 |
|---|---|---|
| `"i1" / "i2" / "i4" / "i8"` | int8 / int16 / int32 / int64 | 1 / 2 / 4 / 8 |
| `"u1" / "u2" / "u4" / "u8"` | uint8 ... | 1 / 2 / 4 / 8 |
| `"f2" / "f4" / "f8"` | float16 / float32 / float64 | 2 / 4 / 8 |
| `"?"` | bool | 1 |

### `astype` —— 类型转换

```python
arr1 = np.zeros((2,3), dtype=np.int64)
arr1.astype(np.float64)         # 返回新数组（int → float）
```

🔥 **关键认知**：`astype` 返回**新数组**，原数组不变。

→ 详细见 [[day01_02_数据类型教程]]。

## 速查 API 表

```python
# 属性
arr.ndim / shape / size / dtype / itemsize

# 从列表造
np.array([1,2,3])
np.asarray(arr)              # 不拷贝（如果入参已是 ndarray）

# 全 0 / 全 1 / 全指定值
np.zeros((2,3))
np.ones((2,3))
np.full((2,3), 6)
np.empty((2,3))              # 未初始化，最快

# 仿 shape 造
np.zeros_like(arr)
np.ones_like(arr)
np.full_like(arr, 8)

# 等差 / 等比序列
np.arange(0, 10, 2)                    # [0,2,4,6,8]
np.linspace(0, 10, 5)                  # 5 个等分点
np.linspace(0, 10, 5, endpoint=False)
np.logspace(2, 5, 4, base=2)           # [4,8,16,32]

# 随机数
np.random.seed(42)                     # 固定种子（可复现）
np.random.rand(2, 3)                   # [0,1) 均匀
np.random.randint(0, 5, size=(2,3))    # 整数
np.random.uniform(0, 5, size=(2,3))    # 浮点均匀
np.random.randn(2, 3)                  # 标准正态

# 矩阵（不推荐用）
np.matrix("1,2;3,4")

# 数据类型
arr = np.array([1,2,3], dtype=np.float64)
arr = np.array([1,2,3], dtype="i8")     # 字符串简写
arr.astype(np.float32)                  # 类型转换（返回新数组）
```
