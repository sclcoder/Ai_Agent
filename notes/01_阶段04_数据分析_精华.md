## 🟦 时间序列 4 件套

Pandas 时间处理的 4 个核心动作。会这 4 个就够 90% 场景。

### 1. 字符串 → datetime（最常用）

```python
import pandas as pd

# 方式 A：先读后转（常见）
df = pd.read_csv("xxx.csv")
df["date"] = pd.to_datetime(df["date"])

# 方式 B：读的时候直接转（推荐，省一行）
df = pd.read_csv("xxx.csv", parse_dates=["date"])

# 方式 C：格式混乱时（"2015-Jul-6"、"07-07-2015"、"20150708" 混着）
pd.to_datetime(["4th of July, 2015", "2015-Jul-6", "07-07-2015", "20150708"],
               format="mixed")
```

**iOS 类比**：相当于 `DateFormatter`，但 `format="mixed"` 是杀手锏 —— Apple 没这玩意。

### 2. 提取年月日（必背）

```python
# Series 上必须用 .dt 访问器
df["year"]    = df["date"].dt.year
df["month"]   = df["date"].dt.month
df["day"]     = df["date"].dt.day
df["quarter"] = df["date"].dt.to_period("Q")   # 季度
df["weekday"] = df["date"].dt.weekday          # 星期几（0=周一）

# 单个 Timestamp 不用 .dt
ts = pd.Timestamp("2015-01-01 09:08:07")
ts.year, ts.hour, ts.microsecond
```

**坑**：忘了 `.dt` 直接 `df["date"].year` —— 报错。Series 必须 `.dt`，单值不用。

### 3. 时间差与时间索引

```python
# 时间差：减出来是 timedelta64
df["days_from_start"] = df["date"] - df["date"][0]

# 把日期设为索引（resample 必备）
df.set_index("date", inplace=True)
```

### 4. 重采样 resample（时间序列的 groupby）

```python
df.set_index("date", inplace=True)

df[["temp_max", "temp_min"]].resample("ME").mean()   # 按月末聚合
df[["temp_max", "temp_min"]].resample("YE").mean()   # 按年末聚合
df["price"].resample("W").sum()                       # 按周求和

# 生成时间序列（造测试数据 / 补齐缺失日期）
pd.date_range("2015-07-03", periods=10, freq="QE")    # 季度末，10 个
pd.date_range("2015-07-03", end="2015-07-10")         # 起止
```

频率字符串：`D 日 / W 周 / ME 月末 / QE 季末 / YE 年末 / h 小时`（pandas 2.0+ 推荐用 `ME` 不用 `M`）。

## 🟩 groupby 进阶（agg / transform / filter）

**这是阶段04 唯一文档讲不清的地方，必须背。**

### 套路对比表

| 方法 | 返回形状 | 典型用途 |
|---|---|---|
| `agg` | **缩小**（每组一行） | 求和、均值、自定义聚合 |
| `transform` | **保持原形** | 按组中心化、按组填空、相对组内排名 |
| `filter` | **筛选行**（保留/丢弃整组） | "丢掉销售额低于均值的整个部门" |

### agg：标准聚合

```python
# 多个聚合函数
df.groupby("department_id")["salary"].agg(["min", "max", "median"])

# 不同列用不同函数 + 改列名
df.groupby("department_id").agg({
    "job_id": "nunique",        # 工种数
    "commission_pct": "mean"    # 提成均值
}).rename(columns={"job_id": "工种数", "commission_pct": "平均提成"})

# 自定义聚合函数（接收一组 Series，返回单值）
def initials(x):
    return set(name[0] for name in x)
df.groupby("department_id")["last_name"].agg(initials)
```

### transform：**最容易忽视、最有用的**

```python
# 模式 1：按组中心化（减去组均值）—— 模型预处理常用
df.groupby("department_id")["salary"].transform(lambda x: x - x.mean())

# 模式 2：按组均值填充缺失值 —— 数据清洗杀手锏
def fill_with_group_mean(x):
    return x.fillna(x.mean() if not np.isnan(x.mean()) else 0)
df["salary"] = df.groupby("department_id")["salary"].transform(fill_with_group_mean)

# 模式 3：组内排名 / 占比
df["salary_pct_in_dept"] = df.groupby("dept")["salary"].transform(lambda x: x / x.sum())
```

> **为什么是 transform 不是 agg**：transform 返回值的长度等于原 df 行数，可以直接赋值回原表的列。`agg` 返回每组一行，对不齐。

### filter：按组级条件筛选

```python
# 保留"该组里 commission_pct 全部非空"的整组
df.groupby("department_id").filter(lambda g: g["commission_pct"].notnull().all())

# 保留"该组人数 > 10"的整组
df.groupby("department_id").filter(lambda g: len(g) > 10)
```

### cut：连续值分箱（搭配 groupby 用）

```python
# 等距分箱（自动）
pd.cut(df["salary"], 3)

# 自定义边界 + 标签
pd.cut(df["salary"], [0, 10000, 20000], labels=["low", "high"])

# 实战：按薪资段分组统计
df["salary_band"] = pd.cut(df["salary"], [0, 5000, 10000, 20000], labels=["低", "中", "高"])
df.groupby("salary_band", observed=True)["commission_pct"].mean()
```

## 🟨 业务模式：链式排序去重「取每组最值」

来自 day03/P05_Weather，**比 groupby + max 更灵活**的常用套路。

### 模式：取每年最热的那一天的完整信息

```python
# 错误想法：df.groupby("year")["temp_max"].max() —— 只能拿到温度，丢了那天的其他列
# 正确做法：
df["year"] = pd.to_datetime(df["date"]).dt.year
year_sort = df.sort_values(by=["year", "temp_max"], ascending=[True, False])
year_sort.drop_duplicates(subset=["year"])   # 每年保留排在第一的那一行（即最热那天的完整记录）
```

**何时用**：要保留极值所在行的**完整上下文**（不只是极值本身）。
- 取每个用户最近一次订单（按 user 分组，按 date 降序，drop_duplicates(subset=user)）
- 取每个分类销量第一的商品
- 取每天访问最频繁的 IP

### 模式：先取极值再筛子集

```python
# "最高温度最高的 30 天里，最低温度最低的 5 天"
df.nlargest(30, "temp_max").nsmallest(5, "temp_min")
```

**何时用**：先粗筛再细筛的两阶段排序，比写嵌套条件清晰得多。

## 🟥 端到端数据分析项目模板

来自 day05/P06_House_Sale。**这是整个阶段唯一的端到端项目，背模板**。

### 完整 6 步骤

```python
# === Step 1：导包 + 中文字体 ===
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from matplotlib import rcParams
rcParams["font.sans-serif"] = ["SimHei"]   # macOS 用 "PingFang SC" 或 "Arial Unicode MS"

# === Step 2：加载 + 清洗 ===
data = pd.read_csv("house_sales.csv")
data.dropna(inplace=True)

# IQR 法去离群点（统计学经典手法）
Q1, Q3 = data["price"].quantile(0.25), data["price"].quantile(0.75)
IQR = Q3 - Q1
data = data[(data["price"] >= Q1 - 1.5 * IQR) & (data["price"] <= Q3 + 1.5 * IQR)]

# === Step 3：类型转换 ===
data["date"] = pd.to_datetime(data["date"])

# === Step 4：特征工程（派生列）===
data["age"] = data["date"].dt.year - data["yr_built"]            # 房龄
data["is_renovated"] = (data["yr_renovated"] > 0).astype(int)    # 是否翻新（0/1）

# === Step 5：描述性统计 + 相关性 ===
numeric_cols = data.select_dtypes(include=[np.number]).columns
data[numeric_cols].describe()
data[numeric_cols].corr()["price"].sort_values(ascending=False)   # 各列与目标的相关性

# === Step 6：多维聚合 ===
# 按一个维度
data.pivot_table(values=["price", "sqft_living"], index="zipcode", aggfunc="mean")

# 连续变量先分箱再分组
data["age_group"] = pd.cut(data["age"], 5)
data.groupby("age_group", observed=True)["price"].mean()

# 两个维度交叉（年 × 是否翻新）
data.pivot_table(values="price",
                 index=data["date"].dt.year,
                 columns="is_renovated",
                 aggfunc="mean")

# === Step 7：可视化 ===
plt.figure(figsize=(10, 6))
plt.hist(data["price"], bins=30, edgecolor="k")
plt.title("房价分布")
plt.show()
```

### 这个项目的「真·学习点」

不是代码本身，是**这套思路**：

1. **离群点用 IQR 不用 3σ** —— 3σ 假设正态分布，IQR 不假设，对偏态分布（价格、收入这种）更稳。
2. **从原始时间字段派生「相对时间」特征**（房龄 = 售出年 - 建造年）。raw `yr_built` 当特征几乎无用，`age` 才有信号。
3. **`pivot_table` vs `groupby` 的取舍**：
   - 一维聚合两者等价
   - **二维交叉**（行一个维度、列另一个维度）`pivot_table` 比 `groupby + unstack` 简洁
4. **相关性接近 0 不代表无关** —— 房价例子里所有特征相关性 < 0.012，说明：要么数据是合成的、要么线性相关漏掉了非线性关系（zipcode 聚类、地理位置 lat/long）。**这是经典的「先看图再下结论」的提醒**。

### 可以自己扩展的点（原项目没做）

- `lat/long` 完全没用 —— 可以加地理聚类（KMeans）或按经纬度分箱看价格分布
- 没做时序分析 —— 用 `resample("YE")` 看年度均价趋势
- 没建模 —— 接 sklearn 跑个线性回归看看哪些特征真的有用
